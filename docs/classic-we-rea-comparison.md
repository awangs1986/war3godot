## 4. 逐项结论

高度内部表示：`world = float((h&0x3fff|0x22c000)<<9) − 6144`，写回 `h = trunc((world+2048)·4)`，即 1 raw = 0.25 world，512 raw = 128 world = 1 层。

- **升/降**：`Δworld = cos(dnorm·π/2)·s·6.4`，`dnorm = √(dx²+dy²)/(s−1)`，只取 dnorm ≤ 1；降和 Shift 各乘 −1。6.4 world = 25.6 raw = 0.05 层。形状：**升/降永远按圆形**。
- **整平**：值 = 按下时捕获的 h0（`this+0x948`），覆盖集合遵守形状（方形可用）。
- **噪声**：`n = int(128/6.4)+1 = 21`，`Δ = (rand%21 − 10)·6.4 world`。遵守形状。
- **平滑**：在快照缓冲（`this+0x1c4`）上做 3×3 核 `[1,2,1;2,0,2;1,2,1]`（中心权 0，除以 12）：`new = trunc(Σ/12·W2 + h·W1)`，float32 计算。普通 W1=0.8,W2=0.2；Shift W1=1.00,W2=0.05。遵守形状。
- **坡度钳制（整平边缘 h0−611 的真正原因）**：每次高度写回后，对每个改动点求允许区间 `[MinHeight−L·128, MaxHeight−L·128] ∩ [邻居 ± S]`，正交邻居 `S = tan(50°)·128 = 152.55 world = 610.2 raw`，对角 `tan·181.02`；越界就夹回并递归复查邻居。仅当 MaxSlope < 85 生效。例：整平到 9111 后，圈外 (33,24) 被抬到 `trunc(9111−610.2)=8500`；与相机方向无关，只是那次实验只有南侧坡度超限。
- **悬崖 ±2/±1/同层**：目标 `T = L(中心)+Δ`，按下时捕获（`this+0x94c`）；**T 越出 [0, maxLayer] 时整笔不执行**（拒绝而不是夹）。每点再夹到 `[水决定的下限, maxLayer]`，且夹后的值会覆盖 T 影响后续点（实现怪癖）。覆盖：圆 `dist²/(s−1)² ≤ 1`，方形全部。`0x5748c0` 把悬崖类型+随机变体写到 3×3 外扩。
- **层差传播（`0x573990`）**：对每个改动点的 8 邻居，若层差 > 2 就拉到 “中心 ∓ 2”，**同时写入所选悬崖类型和随机变体**，再递归（递归深度记在顶点字节 +0xb 防重入）。
- **悬崖后高度修正（`0x57ef30`）**：层变化后若某点世界高度超出 MaxHeight/MinHeight，按 cos 衰减把周围一片高度拉回。
- **浅水/深水（`0x603cc0`）**：干地上浅水 Δ层 = −1、深水 = −2；已是水的点按现有水面算 Δ。先在半径 s−1 内设水标志并写水面高度，再调用高度笔刷**整平(op 2)，尺寸 s+2，值 = 点击点地面**，再调用悬崖笔刷（尺寸 s，目标层为上面算的层）。
- **坡道（`0x583310`）**：取鼠标所在格，比较相邻角的层差，只有正交方向层差恰为 1（或两个方向都为 1 且对角同层的拐角情形）才执行，否则直接返回。
- **贴图 / 荒芜 / 边界**：只定位到边界入口 `0x5f7d10`（建 undo 组后转 `0x5f8070/0x63c250`）；贴图和荒芜的写入函数本轮**未定位**，没有源码结论。
