# 可折叠小地图侧栏设计

## 目标

W3Editor 的整个左侧栏（小地图、地图信息和图层）允许隐藏。隐藏后中央视口占用释放出的空间，用户可以通过顶部工具栏按钮重新打开侧栏。

## 交互

- 左侧栏标题区域提供关闭按钮。
- 顶部工具栏提供“小地图面板”切换按钮。
- 隐藏时同时折叠左栏及其右侧分隔条。
- 顶部按钮显示当前开关状态；再次点击恢复侧栏。
- 切换只改变布局，不销毁控件，不清除小地图、地图信息或图层状态。
- 每次启动编辑器时默认显示左侧栏；本次改动不持久化用户偏好。

## 实现

- 为主体 `Grid`、左侧 `Border` 和左分隔区域增加名称。
- 使用一个统一方法切换左栏可见性以及对应列宽：
  - 显示：左栏 `264`，分隔列 `6`。
  - 隐藏：左栏 `0`，分隔列 `0`。
- 顶部工具栏按钮和侧栏关闭按钮调用同一切换方法，避免状态分叉。
- 中央视口继续使用星号列宽，无需额外尺寸计算。

## 验收

- 初始状态左栏可见。
- 点击侧栏关闭按钮后，左栏和分隔条消失，中央视口扩展。
- 点击顶部按钮后，左栏恢复为原宽度，已有内容不变。
- 连续切换不会产生布局漂移或异常。
- W3Editor Release 构建无警告、无错误。
