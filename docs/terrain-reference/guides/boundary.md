# 边界（放置 / 移除）

> 参考实现：`src/TextureBrushes.cs:42-46（Boundary）`　对照结果：13/13（100%）（完整表格见 `../results.md`）
> 验证范围：仅1.32存档（1.27 只到入口 0x5f7d10）。


## 原理
只改 boundary 标志，其它字段不动。

**实测（单角点、尺寸 1，fixtures `C0/C1/C2`）**
- 放置：**恰好 1 个角点** `(33,30) boundary False→True`
- 移除：**恰好 1 个角点** `(33,30) boundary True→False` ⇒ **同一角点，放置/移除对称** ✓
- 建议用 `tools/w3e_diff.py --only=boundary` 核对（`--only` 会剔除无关字段）

> ⚠ **一处已收窄的旧表述**：本文原写"放置后再移除，存档与原图**逐字节相同**" ✗ ——
> 实测 `C0` vs `C2` 仍有 **23 处差异**，全部是 `cliffVar`/`cliffType`/`layer`（来自该实验里**前一笔悬崖点击**的残留），
> **boundary 位本身确实回到 0** ✓。正确说法是"**boundary 位恢复原状**"，不能推广成"整个存档逐字节相同" ✓。
