# 浅水 / 深水

> 参考实现：`src/CliffBrushes.cs（Water）`　对照结果：浅水 211/211、深水 211/211、已有水上放深水 21/21（1 例）（完整表格见 `../results.md`）

## 原理
读中心原层级 L0、原高度 h0。三个范围各写不同字段：d ≤ R 层级 L0−1（浅）或 L0−2（深）并设 water；外扩一圈 waterHeight = h0 + (L0−2)·512、悬崖类型；d ≤ R+2 地面高度全部设为 h0。先整平再降层，所以水深只取决于降了几层，岸边也平整。

## 一步步的数值推演
`A_raise3`（中心 h0 = 8576，L0 = 2）上放 s3 浅水：
1. 13 个点层级 2 → 1，water = 1。
2. 37 个点 waterHeight = 8576 + 0 = 8576。
3. 49 个点 groundHeight → 8576（原来 8192..8546）。
渲染：地面 z = (8576−8192)/4 + (1−2)·128 = −32；水面 z = (8576−8192)/4 − 0.7·128 = 6.4；水深 38.4。

## 第五轮：水笔刷 = 写水 + 整平 + 悬崖（1.27 源码 0x603cc0）
1. 点击点：干地 Δ = 浅 −1 / 深 −2；已是水：Δ = floor((水面 − 地面总高)/128)，水面 = 现有水面 + 水偏移（深水再减 DeepExtra）。T = L + Δ，h0 = 点击点地面。
2. 覆盖集合设水标志；外扩一圈写水面（外扩一圈是 1.32 实测；1.27 这一步只看到覆盖集合，差异待查）。
3. 调用**整平**，尺寸 s+2，值 h0——走 `HeightPipeline`，所以陡坡上会被坡度钳制。
4. 调用**悬崖笔刷**，尺寸 s，目标 T——越界整笔拒绝、层差传播、写悬崖类型都生效。
