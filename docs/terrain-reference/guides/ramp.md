# 坡道

> 参考实现：`src/CliffBrushes.cs:112-141（Ramp）`　对照结果：19/19（100%）：南、东、北（坑内）、凸角 3×3、两层差不生效（完整表格见 `../results.md`）

## 原理
坡道只写 ramp 标志，不改层级。点击处必须是低地角点，紧挨着**高 1 层**的悬崖边：沿垂直悬崖边写 3 个角（外侧低、点击处低、高侧 1 个）。台地凸角斜外侧写 3×3；层差 2、点在高处、凹角都不生效。

## 一步步的数值推演
`R1_base` 台地 x31..35、y28..32（层 3）。点 (33,27)：北邻 (33,28) 层 3 = 2+1 → 写 (33,26)、(33,27)、(33,28)。点 (30,27)：4 邻都不更高，斜邻 (31,28) 高 1 层 → 写 (29..31)×(26..28) 共 9 个。
