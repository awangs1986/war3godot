# 整平

> 参考实现：`src/HeightBrushes.cs:35-41（Plateau）`　对照结果：91/93（97.8%），2 个不一致点都在相机一侧边缘（完整表格见 `../results.md`）

## 原理
按下那一刻读中心角点高度 h0，把 d ≤ R 内全部设成 h0，没有衰减；拖动时仍用按下时的 h0，所以能“推”出一块平台。

## 一步步的数值推演
`P2_base2` 上 s5（R = 4）整平，中心 h0 = 919（相对 8192）：
1. 圈内 46 个点全部 → 919，比如原来 391 的点变成 919。
2. 南侧 d = 4 的点官方是 918（差 1），d = 5 的点 223 → 308。
3. 308 = 919 − 611。另外两次实验也满足“圈外紧邻点 ≥ h0 − 611”，这是边缘过渡的经验规律（见 12.3），参考实现故意不模拟。

## 常见误区（对照你现在的写法）
- 不要把 +85 当成鼠标抖动：同一配方 12 次结果完全相同。
- 整平不受 Shift 影响，也不受尺寸形状影响。
