# 高度插值

> 参考实现：`src/Rendering.cs:10-22（GroundZ、Bilinear、Triangle）`　对照结果：无官方数值（渲染端）；自检：同一格双线性与三角最大相差 1.38 世界单位（完整表格见 `../results.md`）

## 原理
角点世界高度 = (h−8192)/4 + (L−2)·128。格子内部插值必须和三角化一致，地面、悬崖、水都用同一种。

## 一步步的数值推演
角点 z = 0、0、0、10：格中心双线性 = 2.5；三角（沿对角线）= 5 或 0。

- 你的仓库悬崖用双线性（`TerrainSurfaceGeometry.cs:43`），地面用三角（`:21-24`），悬崖底边会裂缝。
