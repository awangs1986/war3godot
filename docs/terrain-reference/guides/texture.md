# 贴图

> 参考实现：`src/TextureBrushes.cs:11-21（Texture）`　对照结果：51/51（100%），圆形和方形（完整表格见 `../results.md`）

## 原理
覆盖集合内 groundTexture = 所选下标，并重新随机变体。贴图不影响层级、水、坡道。

## 一步步的数值推演
s3 圆形 13 个点改成 tex1；方形 25 个点。变体约 91% 落在 {0,4,8,12,16,17}。
