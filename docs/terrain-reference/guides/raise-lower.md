# 升高 / 降低

> 参考实现：`src/HeightBrushes.cs:18-35（RaiseLower）`　对照结果：raise 201/201，lower 18/18（100%）（完整表格见 `../results.md`）
> 验证范围：1.27源码+1.32存档验证。


## 原理
官方的升高/降低是**一次按下施加一次**的“盖章”，不是按帧持续增长。增量只跟尺寸 s 有关：中心 0.05·s 层，向外按余弦衰减，在 d = R（R = s−1）处正好降到 0，所以实际改动的是 d < R 的点。为什么用余弦：它在中心是平的、在边缘斜率为 0，盖章叠加时不会出现尖锐的环。

## 一步步的数值推演
以 s = 3 为例（R = 2，1 层 = 512 raw）：
1. 中心 d = 0：0.05×3×512×cos(0) = 76.8 → 向下取整 **76**。
2. 上下左右 d = 1：76.8×cos(π/4) = 54.3 → **54**。
3. 斜角 d = √2：76.8×cos(π·1.414/4) = 34.5 → **34**。
4. d = 2：cos(π/2) = 0 → 不变。
降低把符号放进取整里：floor(−76.8) = **−77**，floor(−54.3) = −55，floor(−34.5) = −35，和存档 `lower_s3_c_h08` 完全一致。

## 常见误区（对照你现在的写法）
- 你的 `TerrainBrush.cs:316-321` 用 `frameDelta × 线性衰减`：按住越久越高，官方按住多久都一样。
- 方形笔刷对高度类无效，官方一律按圆形算。
- 降低不是“升高取负再取整”：−floor(76.8) = −76，而官方是 floor(−76.8) = −77。
