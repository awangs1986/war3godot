# 海岸

> 参考实现：`src/Rendering.cs:50-51（WaterZ、Depth）`　对照结果：无官方数值；自检：`LS04_deep` 全水格 34、岸边格 38（完整表格见 `../results.md`）

## 原理
水深 = 水面 − 地面，水面 = (w−8192)/4 + 水偏移·128。岸边角点水深 ≈ 0，渲染时按水深渐变透明度和颜色；编辑器不画岸边贴图。

## 一步步的数值推演
L 图平地放浅水：地面 z = −128（层 1），水面 z = 0 − 89.6 = −89.6，水深 38.4（浅水色）；深水层 0：水深 166.4。
