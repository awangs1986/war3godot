# 荒芜

> 参考实现：`src/TextureBrushes.cs:27-40（Blight）`　对照结果：blight 标志 13/13（100%）；外围随机贴图无法逐点对照（完整表格见 `../results.md`）
> 验证范围：仅1.32存档（1.27 写入函数未定位）。


## 原理
**位的位置（权威表，别记混）**
- **w3e 文件**：`byte4` 的 `0x20` 位（同一字节低 4 位是纹理索引，`0x10` 坡道 / `0x40` 水 / `0x80` 边界）
- **编辑器内存记录**：标志字在 `word[+0x0c]`，其中 **blight = bit2 (`0x0004`)**、跳过=bit0、有水=bit4(0x0010)、边界=bit6(0x0040)
- **纹理刷会清 blight**（B 级）：`ghidra_286a60.c:190` `uVar6 = 0xfffb` → `:192` `auStack_d0._12_2_ &= uVar6`（清 bit2）；
  但**没有官方存档覆盖**该路径 ⇒ A 级仍缺。详见 `../experiments/CORRECTIONS.md` 顶部时间线与 §19。

覆盖集合内设 blight 标志；外围约 R+2 内随机把一部分角点贴图改掉，形成不规则边缘；水角点不接受荒芜。

`T_blight_s3`：13 个点 blight = 1，另外 18 个点 tex 被随机改写，共 31 个改动。

## 常见误区（对照你现在的写法）
- 你的仓库没有荒芜按钮。
- 荒芜在渲染时永远在最上层。
