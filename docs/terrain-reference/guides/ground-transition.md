# 地表过渡接缝

> 参考实现：`src/Rendering.cs:30-46（GroundLayers）`　对照结果：无官方数值；自检：`MX_quad` 4 贴图同格得到掩码 0001/0010/0100/1000，与截图一致（完整表格见 `../results.md`）

## 原理
渲染格以 4 个角点为四角；每种贴图一层，按下标从小到大叠放，掩码表示哪些角是这种贴图。悬崖格的 4 个角用悬崖类型地表，并参与邻格掩码，所以悬崖草地会向外溢半格。

## 一步步的数值推演
角点 tex = [1,2,3,4] → 层 tex1:0001、tex2:0010、tex3:0100、tex4:1000。

## 对应代码
`src/Rendering.cs:30-46（GroundLayers）`。代码里每一段都有中文注释说明“为什么这样做”。

## 常见误区（对照你现在的写法）
- `GroundLayout.cs` 混用了 HiveWE 和 Warsmash 两套规则。
- 悬崖格只替换自己、不参与邻格掩码，接缝就会出现硬边。
