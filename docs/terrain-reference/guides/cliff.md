# 悬崖升降与传播（−2 / −1 / 同层 / +1 / +2）

> 参考实现：`src/CliffBrushes.cs:20-55（Cliff、Propagate）`　对照结果：单次 150/150（100%）；连点（cliff_repeat）77/81（95.1%）（完整表格见 `../results.md`）

## 原理
目标层 T = clamp(L(中心)+k, 0, 15)，覆盖集合内层级全部设为 T；悬崖贴图写到覆盖集合外扩一圈（3×3 膨胀）。然后传播：任意两个 8 邻接角点层差不能超过 2，超过就把外侧拉到“内侧 ∓ 2”，再从被拉的点继续 BFS。

## 一步步的数值推演
层 2 平地，s1 同一点 +2 两次：
1. 第一次：中心 2 → 4，邻居是 2，差 2，合法，不传播。
2. 第二次：中心 4 → 6，8 个邻居差 4 > 2 → 拉到 4，再外一圈差 2，停止。
结果就是 6/4/2 的方锥（存档 `P_c+2_s1_x3`）。

## 常见误区（对照你现在的写法）
- 你的 `:458` 写的是 `k == 0 && l == 0`，应该是 `k == i && l == j`；`:462` 的 `(l − k)` 应为 `(l − j)`。
- 传播时不要给邻居染悬崖贴图（`:457`），贴图只在笔刷外扩一圈写。
- 用 4 邻接传播会得到菱形，官方是方形。
- 连点实验里光标会落到已抬高的地形上，换到别的角点；`P_c+2_s1_x3` 存了 3 次点击，但只有 2 次落在同一点。
