# 噪声

> 参考实现：`src/HeightBrushes.cs（Noise）` + `src/HeightPipeline.cs`　对照：6 个存档。逐点检查官方存档**和参考实现输出**的范围 + 量化格点（601/601）；k 的分布做统计比较（见 `../results.md` 噪声分布表）。

## 原理
1.27 源码 `0x581460`：n = int(128/6.4)+1 = 21，k = rand%21 − 10，覆盖集合（遵守形状，方形可用）内每个角点独立加 k × 6.4 world = k × 25.6 raw（0.05 层），没有衰减；写完和整平一样做坡度钳制。所以一次噪声最多 ±0.5 层，而且每一步都是 25.6 raw 的倍数（取整后 25 或 26）。

## 一步步的数值推演
k = 3 → 3×0.05×512 = 76.8 → 76；k = −7 → −179.2 → −180。s5 的覆盖集合有 49 个点，其中 k = 0 的点不变，所以存档里通常只看到 45–48 个点改动。

## 对应代码
`src/HeightBrushes.cs:47-55（Noise）`。代码里每一段都有中文注释说明“为什么这样做”。

## 常见误区（对照你现在的写法）
- 你仓库里的 `Ripple` 是空实现（`TerrainBrush.cs:308-312`），官方没有 Ripple，只有 Noise。
- `NoisePercent=10` 是小地图参数，与笔刷无关。

## 测试怎么比（第五轮改）
随机序列对不上官方，所以分三层：
1. 范围：官方和参考实现改动的点都必须在覆盖集合内；
2. 量化：每个改动都必须等于某个 k∈[−10,10] 的 trunc(world + k·6.4)；
3. 分布：官方 k 的直方图与参考实现 200 个种子的平均直方图比总变差距离（TV），和“均匀抽样本身的波动量级”对照。
验证范围：**1.27源码+1.32存档验证（统计）**；方形噪声 **仅1.27源码**。
