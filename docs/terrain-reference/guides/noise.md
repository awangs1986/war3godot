# 噪声

> 参考实现：`src/HeightBrushes.cs:49-66（Noise）`　对照结果：47/47 个官方改动点都落在覆盖集合内且 |Δ| ≤ 256（范围一致率 100%；随机值本身无法逐点对照）（完整表格见 `../results.md`）

## 原理
1.27 源码 `0x581460`：n = int(128/6.4)+1 = 21，k = rand%21 − 10，覆盖集合（遵守形状，方形可用）内每个角点独立加 k × 6.4 world = k × 25.6 raw（0.05 层），没有衰减；写完和整平一样做坡度钳制。所以一次噪声最多 ±0.5 层，而且每一步都是 25.6 raw 的倍数（取整后 25 或 26）。

## 一步步的数值推演
k = 3 → 3×0.05×512 = 76.8 → 76；k = −7 → −179.2 → −180。s5 的覆盖集合有 49 个点，其中 k = 0 的点不变，所以存档里通常只看到 45–48 个点改动。

## 常见误区（对照你现在的写法）
- 你仓库里的 `Ripple` 是空实现（`TerrainBrush.cs:308-312`），官方没有 Ripple，只有 Noise。
- `NoisePercent=10` 是小地图参数，与笔刷无关。
