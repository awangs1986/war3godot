# 1.32.10 地形刷子：内存动态捕获 + 反编译确认

> 捕获日期：2026-10-16 ｜ 版本实证：`World Editor.exe` = **1.32.10.18820**（ProductVersion `1.32.10.18820 (f1d8377869)`，链接日期 2022-06-08）；`Warcraft III.exe` 同为 1.32.10.18820。
> 对照：经典 1.27 `WorldEdit.exe` = 5,103,592 B（本编辑器为 27,285,960 B，非"老版本编辑器"）。
> 本文所有结论均为 **1.32 动态捕获 + 反编译确认**（非 1.27 推断），除非明确标注。

---

## 1. 捕获方法（动态）

1. **磁盘 `.text` 是加密/打包的**：`.text` VA=0x1000, VSize=0x12992bc（18.60 MB）, RawOff=0x400；熵 **7.999**（接近纯随机）。
2. **运行中内存里已解密**：从进程读取模块基址起 28 MB 内存块，`.text` 熵降到 **6.674**，且出现真实编译器特征：
   - `48 89 5C 24 08`（mov [rsp+8],rbx）×11863
   - `48 83 EC`（sub rsp,x）×49114，`CC CC CC CC` int3 填充 ×49265
   - 仅开头约 700 KB 仍为高熵（壳头 stub）。
3. **重建"已解密 PE"**：按 PE 段表把内存各段回填进磁盘文件（`.text/.rdata/.data/.pdata/_RDATA/.rsrc`），得到可静态分析的全新 PE。
4. **Ghidra 12.1.4 无头分析 + 定向反编译**：定位到 4 处 `6.4f` 引用、`50f`(MaxSlopeDeg)、`0.8f/0.2f`(平滑权重) 等常量点，逐函数反编译。
5. 交叉验证：Windows VM（原生进程，ReadProcessMemory）与 Linux/Proton（Wine，winedbg）两侧独立确认同一布局与常量。

## 2. 地形角点在内存中的布局（反编译直接给出）

```c
iVar1      = *(int *)(map + 0xf4);                 // 宽度(tiles)
y = idx / (iVar1 + 1U);  x = idx % (iVar1 + 1U);   // 角点索引：每行 = 宽+1
uint32 rec = *(uint *)(idx * 0x1c + *(longlong *)(map + 0x188));
```

| 位置 | 含义 |
|---|---|
| `[map+0x188]` | **角点数组基址指针** |
| 记录步长 | **0x1C = 28 字节** |
| `rec+0x00`（dword） | 低 **14 位** = raw 高度（8192 基准）；高位另有水/边标志 |
| `rec+0x0a`（byte） | 低 4 位 = 纹理层号 → 世界高度偏移 `层×128 − 256` |
| `[map+0xf4]` / `[map+0xf8]` | 宽度 / 高度（tiles） |
| `[map+0x180]` | 角点总数 |
| `[map+0xb94]` | 按下瞬间抓取的**目标高度**（世界单位 float） |
| `[map+0xbc4]` / `[map+0xbc8]` | 允许高度**下界 / 上界**（float） |
| `[map+0xbcc]` | 水位/门限常量（与 **85.0** 比较） |
| `[map+0xbd0]` | 高度步长缩放（崖/坡邻居步长系数） |

## 3. 高度编码 / 解码（浮点位技巧）

```c
// 解码 raw -> 世界单位（1.32 实际代码）
h_world = (float)(( (raw & 0x3fff) | 0x22c000 ) << 9) - 6144.0;   // == (raw - 8192) * 0.25

// 编码 世界单位 -> raw
corner = (corner & 0xffffc000) | (uint)( (h_world + 2048.0) * 4.0 );   // == ToRawWorld

// 清零高度（随机化/重置分支）
corner = (corner & 0xffffe000) | 0x2000;   // = 8192 = 高度 0
```
> `6144.0` 不是算法常量，是位技巧产物（`0x45800000`=4096.0 与 −2048 偏移的合成）；`(h+2048)*4` 与 `(v−8192)*0.25` 互为逆运算，确认与既有实现一致。

## 4. 1.32 实测常量表

| 常量 | 值 | 用途（反编译出处） |
|---|---|---|
| StepWorld | **6.4f** | 抬升/降低步长；噪声幅度；崖高范围末尾 `+6.4` |
| 层→世界 | **128.0f** | `层×128 − 256` |
| 对角系数 | **181.01888f = 128×√2** | 斜向邻居步长（正交为 128.0） |
| ToRawWorld | `(h + 2048.0) × 4.0` | 世界→raw 编码 |
| 纹理层偏移 | `层 × 128.0 − 256.0` | 角点实际高度 = raw 高度 − 该偏移 |
| 最大高度 | **2560.0f**（= 20 层 × 128） | 整平/平滑采样 clamp 上界 |
| 崖范围下限 | **−64.0f** 与 **−3.2f** | 两种情形的额外下降量 |
| 水位门限 | **85.0f** | 决定是否展开邻居高度范围（`<=85 && !=85`） |
| 噪声 | `n = (percent × 21) / 100; Δ = (rand[0,n) − n/2) × 6.4f` | 随机化高度（percent 驱动，非固定 21） |
| 整平采样 | 13×13 网格，间距 **50.0**，范围 **±300.0** → 平均 → clamp **[0,2560]** | 另一分支：3×3 加权（间距 **500.0**，权重表 `[obj+0x80]`） |

## 5. 函数地图（1.32.10 绝对地址 = 静态地址，基址 0x140000000）

| 地址 | 作用 |
|---|---|
| `0x140276110` | **刷子应用主循环**：坐标换算、bbox 钳制到 `[0,宽/高]`、按 op 分派（`op==4` 时需临时缓冲 → 平滑类）；开头即 `[map+0x188]+idx*0x1c` 取原始高度写入 `[map+0xb94]` |
| `0x140277a90` | **崖/坡高度范围**：`min/max ± step`（step=128 正交 / 181.01888 对角，×`[map+0xbd0]`）、`−64/−3.2`、`+6.4` |
| `0x1402797a0` | **随机化高度**（`WESTRING_RANDOMIZINGHEIGHTS`）与**清零**分支；噪声与编码写回都在此 |
| `0x1401e2070` | **整平/平滑采样**：13×13 平均 或 3×3 加权 → 写入 `[obj+0x44]` |
| `0x140263fb0` | 坐标/索引换算 |
| `0x1403be070` | 取 3×3 邻居角点指针 |
| `0x140317b40` / `0x140316620` | 邻居/边界判定（决定 `−64.0` / `−3.2`） |
| `0x14014e6a0` | RNG：`rand(0, n)` |
| `0x14013caa0(0x9a)` | 全局状态门（是否允许某些高度修正） |
| `0x1417bc528` | 浮点权重/衰减表（圆形掩码取样用） |

## 6. 相对既有 1.27 静态 RE / 官方参考的新增点

- **对角系数 181.01888（=128×√2）**：崖/坡邻居范围计算里斜向步长是正交的 √2 倍。
- **噪声由参数百分比驱动**：`n=(percent×21)/100`，幅度 `Δ=(rand−n/2)×6.4`（官方参考里的固定 21/−10 是 percent=100 的特例）。
- **整平采样网格**：13×13、间距 50、范围 ±300，clamp 上界 **2560**（=20 层×128）；另有 3×3 加权（间距 500）。
- **崖范围的两个下限 −64.0 / −3.2** 与 **85.0 门限**。
- 编码/解码对：`(h+2048)×4` ↔ `(v−8192)×0.25`（与既有实现一致，现由 1.32 代码实证）。
