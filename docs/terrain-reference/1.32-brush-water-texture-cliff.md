## 0. 公共基础（先读这一节，后面所有工具都复用）

### 0.1 角点记录 28 字节布局（编辑器内部记录）✔

`cornerPtr = [map+0x188] + idx*0x1C`，`idx = y*(width+1) + x`，`width = [map+0xf4]`，`height = [map+0xf8]`，`count = [map+0x180]`（与 `1.32-dynamic-capture.md` 一致，本二进制再次确认）。

| 偏移 | 类型 | 含义 | 关键证据 |
|---|---|---|---|
| `+0x00` | u32 | bit0-13 = 地面高度 raw（8192 基准）；bit14-22 = `X idx` = `x − width/2 + 256`（9bit）；bit23-31 = `Y idx` = `y − height/2 + 256`（9bit） | 建图 `FUN_140264460` @`0x140264460`：`&0xffffe000 | 0x2000`（高度=0）、`&0xff803fff`（bit14-22）、`&0x7fffff`（bit23-31） |
| `+0x04` | u32 | bit0-17 = 角点线性 `idx`；**bit18-31 = 水位 raw**（14bit，8192 基准） | 建图 `0x140264460`：`&0x3ffff | ((fVar19+2048.0)*4.0)<<0x12`；取用 `FUN_140263fb0` `&0x3ffff`、`FUN_140317b40` `>>0x12` |
| `+0x08` | u8 | 低 4bit = 地面纹理槽号（v11）；高 4bit 内部未用（保存时被 flags 覆盖） | 载入 `FUN_140271fb0` @`0x140272128`：`&0xf | (byte)local_res18[0]`；纹理刷 `FUN_140286a60` @`0x140286d92` |
| `+0x09` | u8 | 低 5bit = 悬崖纹理 id；bit5-6 = 悬崖纹理**随机变化量** `Rng(0,3)` | 载入 @`0x14027217f`；写入 `FUN_14026a480` @`0x14026a8ad`（`FUN_14014e6a0(0,3)<<5`） |
| `+0x0a` | u8 | **低 4bit = 层/崖层级 level**；高 4bit = 悬崖类型索引（map 内 cliff-type 表下标） | `FUN_1402797a0` @`0x1402797a0`：`(byte[+0x0a]&0xf)*128.0-256.0`；`FUN_14026a480` @`0x14026a889` |
| `+0x0b` | u8 | 笔刷高亮/命中标记（`1` = 本次笔刷触碰过，用于预览与重算） | `FUN_1403be1b6`（矩形标记）、`FUN_140276110` @`0x140276110`（全清）、`FUN_14026a8ea`（单点置 1） |

`FUN_1403be170`（@`0x1403be170`）= 角点记录"复位"：`+0x00=0x80402000`（高度 8192、XY 居中）、`+0x04=0x80000000`（水位 8192）、`+0x08=0xef, +0x09=0x00, +0x0a=0xf0`、`+0x0b=0`、`+0x10/14/18 = 0.0/0.0/1.0`。

### 0.2 高度编解码 ✔

```c
// raw -> world（三种写法等价，均为位技巧）
h = (float)(((raw & 0x3fff) | 0x22c000) << 9) - 6144.0;   // == (raw - 8192) * 0.25
// world -> raw
raw = (int)((h + 2048.0) * 4.0);                          // == h*4 + 8192
// 层偏移：角点实际顶面 = 地面 raw 解码 + (level*128.0 - 256.0)
```
- 解码例：`FUN_140277a90`@`0x140277a90`、`FUN_140276110`@`0x140276110`、`FUN_14026a480`@`0x14026a4d0` 之后循环。
- **顶面高度统一取用 `FUN_1403bde90(map, cornerPtr, flags)`**（@`0x1403bde90`）：
  `h = decode(u32[0]&0x3fff)`；
  `flags&1` → `+= (byte[+0x0a]&0xf)*128.0 - 256.0`（层）；
  `flags&2` → 若 `word[+0x0c]&2`（ramp）→ `+= FUN_14027eba0(map,x,y,0)`（斜坡插值高度）；
  `flags&4` → 若 `[map+0x9a0]` 存在且 `*(+0x28)>0` → `+= FUN_1403c04f0(map,x,y)`（位移场）。
  工具统一使用 `flags=7`（全量高度）。

### 0.3 世界坐标（用于圆形掩码/距离）✔

`worldX = 128*(x - width/2)`、`worldY = 128*(y - height/2)`，从 `+0x00` 的位域直接位技巧解码（`FUN_14030b260` @`0x14030b3e3`、`FUN_14027d450` @`0x14027d521`）：
```c
fX = (float)(((rec.u32[0]>>23) | 0x11e00) << 14) - 98304.0;   // 98304 = 0x18000
fY = (float)(((rec.u32[0]&0x7fc000) | 0x47800000) & 0xffffc000) - 98304.0;
```

## 1. 水位刷（DeepWater / ShallowWater）

### 对应功能
面板 `MiscBrushes` 组：`DeepWater`（id **5**）、`ShallowWater`（id **6**），本地化键 `WESTRING_DEEPWATER` @`0x1412d45b0` / `WESTRING_SHALLOWWATER` @`0x1412d4598`；状态栏分支见 `0x14040b96b`/`0x14040b982`。处理函数 **`FUN_140314880` @`0x140314880`**（分派条件：`op > 4 && op != 7`，@`0x14017c9c7`-`0x14017c9cd`）。
> 本二进制**没有**独立的"消除水面"刷子（见 §7 UNCERTAIN-1）。

### 算法（`FUN_140314880`，单遍，逐角点）✔

```c
// 参数: map, op(=5 深 / 6 浅), entry[7]=悬崖类型, size, pos*, sink, arg7=“按下帧”标志
if (FUN_14026c340(map, entry[7], 1) == -1) return;      // 悬崖类型解析失败 → 整笔放弃
if (op <= 4) return;                                    // 只处理 op>4
idx  = FUN_140263fb0(map, pos);  x = idx%(w+1); y = idx/(w+1);
corner = base + idx*0x1c;
hasWater = (corner.byte[+0x0c] >> 4) & 1;               // bit4
surface  = FUN_1403bde90(map, corner, 7);               // 含层/斜坡/位移的顶面世界高度

/* ---- 只在按下帧（arg7 != 0）计算整笔目标 ---- */
if (arg7) {
    if (!hasWater) {                                    // 干角点：以“下挖”制造水体
        dLevel = (op==5) ? -2 : (op==6) ? -1 : 0;       // 直接是"层"数（1 层 = 128 世界单位）
        targetLevel = (corner.byte[+0x0a] & 0xf) + dLevel;
    } else {                                            // 湿角点：按“水面 + 该 tileset 水偏移”反推层
        waterW = decode(corner.u32[1] >> 18);
        waterW += *(float*)([map+0x4d8] + 0x108);       // ★ 按 tileset 的水位偏移（Water.slk）
        if (op == 5) waterW -= *(float*)(map + 0x4cc);  // ★ 深水附加：[Water] DeepLevelPathing
        k = (int)((waterW - surface) * 0.0078125f);     // /128，截断
        if (surface > waterW) k--;                      // 地板修正
        targetLevel = (corner.byte[+0x0a] & 0xf) + k;
    }
    ctx[+0x948] = targetLevel;                                     // 目标层
    ctx[+0x94c] = decode(corner.u32[0] & 0x3fff) - 6144.0;         // 地面世界高度
    ctx[+0x950] = hasWater ? decode(corner.u32[1] >> 18) - 6144.0  // 湿：沿用原有水面高度
                           : surface;                              // 干：水面=按下角点顶面
}

/* ---- 逐角点（圆形掩码，见 §0.6） ---- */
for each corner in mask {
     rec.u32[1] = (rec.u32[1] & 0x0003ffff)
                | ((int)((ctx[+0x950] + 2048.0f) * 4.0f) << 18);   // ★ 写水位 raw（bit18-31）
     rec.word[+0x0c] |= 0x0010;                                    // ★ 置“有水”标志
     FUN_1403be230(map, idx, &rec, sink, 0x8000);                   // commit（dirty 位 = 0x8000）
     FUN_140263b00(map, idx, &dirtyVec, 0);
}

/* ---- 收尾：把足印内的“层”统一成 targetLevel ---- */
FUN_140315af0(map, 0);
[map+0xb94] = ctx[+0x94c];                       // 把目标高度写进刷子状态
FUN_140276110(map, 2, size+2, ..., 0, sink);     // 抓目标 + 清 +0x0b + undo 快照
[map+0xb98] = ctx[+0x948];                       // 目标层
FUN_14026a480(map, 2 /*同级*/, entry[7], size, ..., 0, sink);   // 强制层级=targetLevel（挖/填床）
```

### 常量
| 常量 | 值 | 用途 |
|---|---|---|
| 深水层差 | **−2**（层 × 128 = 256 世界单位） | 干角点，op=5 |
| 浅水层差 | **−1**（128 单位） | 干角点，op=6 |
| 层→世界 | `128.0` | `(byte[+0x0a]&0xf)*128 - 256` |
| raw 编码 | `(h + 2048.0) * 4.0` | 水位写回 |
| 水位标志 | `word[+0x0c] |= 0x0010` | bit4 |
| commit 标志 | `0x8000` | `FUN_1403be230` 第 5 参数 |
| tileset 水偏移 | `*(float*)([map+0x4d8] + 0x108)` | 只在**湿**分支参与"层"推算；不参与写盘 |
| 深水附加 | `*(float*)(map+0x4cc)` | `= FUN_140146f20("Water","DeepLevelPathing")`，@`0x140315d24` |
| 归一化 | `0.0078125f = 1/128` | 高度→层 |

### 内存写入
- `corner.u32[1]` bit18-31 ← 水位 raw；`corner.u16[+0x0c]` bit4 ← 1。
- 刷子状态：`[map+0x948]`=目标层、`[map+0x94c]`=目标高度、`[map+0x950]`=目标水面高度（世界）。三者随后喂给 `FUN_14026a480(op=2)`。
- 顺序：**先写水位（所有角点）→ 再统一层（`FUN_14026a480`）**。层改变会连带写 `+0x0a`（level|cliffType<<4）、`+0x09`（悬崖纹理 + `Rng(0,3)<<5`）并做 3×3 扩散（见 §6）。

### 证据（函数地址）
- `FUN_140314880` 全文：`0x140314880`（干/湿分支 `0x14031497f`-`0x1403149f5`；水位写回 `0x140314bf6`-`0x140314c21`；收尾 `0x140314c9b`-`0x140314d19`）。

## 6. 悬崖刷（层级 ±2/±1/0 + 悬崖类型/纹理 + 3×3 扩散）

悬崖在本二进制里由**两条独立路径**实现：
**(A) 层级调整**（面板 `HeightBrushes` 的 5 个按钮，id 0..4 = `op`）→ `FUN_14026a480`；
**(B) 类型/纹理**（面板 `CliffBrushes` 每个 cliff type 一条）→ 作为多标签，落回 `FUN_14027d450` 尾部（`0x14027dc17`）与 `FUN_140286a60`（`+0x09` 写），并且 (A) 每次改层都会做 3×3 扩散把类型/纹理刷到邻居。

### 对应功能
- (A) `"HeightBrushes":"0".."4"`（标题 `WESTRING_HEIGHT` @`0x1412c8ef0`），本地化分支 `0x1401e0b90`-`0x1401e0d34`；op→按钮 = 降两级/降一级/同级/升一级/升两级。
- (B) `"CliffBrushes":"%d"`（逐个 cliff type；tag = cliff type id，@`0x1401e0497`）；本地化键 `WESTRING_APPLYCLIFF` @`0x14132c410`、`WESTRING_APPLYHEIGHT` @`0x14132c428`、`WESTRING_CLIFFLEVEL` @`0x1412e6b70`、`WESTRING_APPLYCLIFF`/`CliffBrush` @`0x14132c398`。
- 悬崖类型解析：`FUN_14026c340` @`0x14026c340`（在 map 的 cliff-type 表 `[map+0x218]`（count `[map+0x210]`，stride **0x168**）里查 tag；缺失且允许则 `FUN_1401cb100` 新建并追加）。

### 6(A) 算法（`FUN_14026a480`，单遍 + 3×3 扩散 + 直方图后处理）✔

```c

  cliffTypeIdx = FUN_14026c340(map, cliffTag, 1);      // → 高 4bit 用的悬崖类型索引
  if (cliffTypeIdx == -1 || op > 4) return;            // 整笔放弃

      [map+0xb98] = (corner.byte[+0x0a] & 0xf) + dLevel;   // ★ 目标层，取自按下角点
  }
  target = [map+0xb98];
  if (target < 0 || target > [map+0xbd4]) return;      // ★ 越界 → 整笔拒绝（不写任何东西）
  histogram[0..[map+0xbd4]] = 0;                       // 0xbd4 = 最大层
  sink 推入更新对象;

  for each corner in mask {                            // 单遍
      rec = *corner;
      /* 逐角点的层修正：仅当“地形限制”开关打开且有水时 */
      if (FUN_14013caa0(0x9a,0)) {
          if (rec.word[+0x0c] & 0x10) {                // 有水

              lvl = (rec.byte[+0x0a] & 0xf) - (2 - k);
              if (lvl >= 0) perCorner = lvl;           // 否则沿用 target
          }

      target = max(target, min(perCorner, [map+0xbd4]));    // 记住本轮用到的最大层
      if ((rec.byte[+0x0a]&0xf) == target && (rec.byte[+0x0a]>>4) == cliffTypeIdx) continue;  // 无变化
      histogram[old level] += 1;

      rec.byte[+0x09] = (rec.byte[+0x09] & 0x1f) | (RNG(0,3) << 5);    // ★ 纹理变化量 0..3
      FUN_1403be230(map, idx, &rec, sink, 0x8000);
      corner->byte[+0x0b] = 1;                                         // ★ 命中标记

      for (i=0..2) for (j=0..2) if (!(i==1&&j==1) && nb[i*3+j]) {
          r2 = *nb[i*3+j];
          r2.byte[+0x0a] = (r2.byte[+0x0a] & 0xf) | (cliffTypeIdx << 4);   // ★ 类型
          r2.byte[+0x09] = (r2.byte[+0x09] & 0x1f) | (RNG(0,3) << 5);     // ★ 纹理变化量
          FUN_1403be230(map, idx, &r2, sink, 0x8000);
      }
      FUN_140263b00(map, idx, &vec, 0);
  }
  /* 后处理：直方图里出现次数最多的层 → 第二遍 FUN_140269520 修高度 */
  (maxCountLevel, maxCount) = argmax(histogram);
  if (maxCount > 0 && 还有角点) for each corner in 掩码: FUN_140269520(map,x,y, cliffTypeIdx, maxCountLevel, idx, sink);

  FUN_1403be5a0(map); FUN_14027e650(map,&vec,sink); FUN_14030eed0(map,sink);
  FUN_140315320(map,&vec,cliffTypeIdx,sink); FUN_14030b870(map,&vec,sink);
  FUN_140277030(map,&vec,cliffTypeIdx);                  // 区域高度重算（内部 → FUN_140276c70）
  FUN_1403be1c0(map?, &bboxRect);                        // ★ 用高亮矩形标记 +0x0b
  ... FUN_14026c810 per chunk; FUN_1403be5a0; FUN_140271390; FUN_1402dd8b0; FUN_1402d9e70; FUN_1402d7b40;
```

### 6(B) 算法（类型/纹理写入点）
1. **3×3 扩散**（见 6(A)）：`+0x0a` 高 4bit = 类型索引，`+0x09` bit5-6 = `Rng(0,3)`。
2. **多标签尾部**（`FUN_14027d450` @`0x14027dc17`，`cliffTypeId != -1`）：
   `byte[+0x08] = (..&0xf0)|(textureIdx&0xf)`，`byte[+0x09] = (..&0xe0)|(cliffTypeId&0x1f)`；
   `cliffTypeId == -1` 时 `+0x09` 改用 `FUN_140286f40(map, textureIdx)`（= `FUN_140145400(map+0xc0,0)`，即"当前悬崖类型"）。
3. **纹理刷同时盖悬崖纹理**（`FUN_140286a60` @`0x140286dd6`-`0x140286df1`）：同上，`+0x09` 低 5bit = `entry[7] & 0x1f` 或当前类型。
4. **悬崖类型表**（`[map+0x210]/[map+0x218]`，stride 0x168）随 `.w3e` 存盘：`FUN_140272420`/`FUN_140272510` @`0x140272420`/`0x140272510`（每个条目写一个 dword）。

### 内存写入
`corner.byte[+0x0a]`（低 4bit = level，高 4bit = 类型索引）、`corner.byte[+0x09]`（bit5-6 = 变化量）、`corner.byte[+0x0b]`（命中）、`word[+0x0c]` 不直接改（层改变不改标志位）。**顺序**：单遍逐角点 → 每个角点即时 3×3 扩散 → 直方图 → 第二遍层修正 → 一串渲染/索引重建。
