## 0. 公共基础

### 0.1 角点记录（28 字节）与高度位域 **[代码]**

```
角点数组基址 = [map + 0x188]        记录步长 = 0x1C (28)
索引 idx     = y * ([map+0xf4] + 1) + x      // [map+0xf4]=宽(tiles)，[map+0xf8]=高，[map+0x180]=角点总数
```

| 偏移 | 内容 | 与高度的关系 |
|---|---|---|
| `+0x00` u32 | **bit0–13 = 地面高度 raw（8192 基准，0.25 世界单位/单位）**；bit14–22 / bit23–31 = 该角点的 X / Y 图块序号（中心化后 +256 的 9 位编码） | 高度刷**只改 bit0–13**，写回时用 `rec & 0xffffc000` 保留 bit14 以上 |
| `+0x04` u32 | bit0–17 = 角点线性索引 idx；bit18–31 = 该角点对应的**水位 raw** | 高度刷不改；但 `FUN_1403be230` 的入口断言要求 `rec[+4] & 0x3ffff == idx` |
| `+0x0a` u8 | 低 4 位 = 层/崖层级 level；高 4 位 = 悬崖类型索引 | 高度刷不改；**层偏移** `level*128 − 256` 参与坡度钳制与噪声/整平的目标高（见 §6） |
| `+0x0b` u8 | 本次笔画/后处理的临时标记（见 §6） | 上次笔画**收尾**时全图清零（`0x140276af0`） |

> **高度域只有 14 位**：raw ∈ [0, 0x3FFF] → 世界高度 ∈ [−2048, 2047.75]。写回时**不做 14 位截断**（`or %eax,%ecx`，`0x140276a1b`），所以若 `[map+0xbc4]`（MaxHeight）被 INI 设成 ≥ 2048 世界单位，高度就会溢出进 bit14（X 序号最低位）——这是原代码的真实约束/隐患，不是本文推断。

### 0.2 高度编解码 **[代码]**

```c
// raw -> world（位技巧，算术等价于 (raw-8192)*0.25）
h = (float)(((raw & 0x3fff) | 0x22c000) << 9) - 6144.0f;
// world -> raw（注意：cvttss2si 是「向零截断」的 C 强制转换）
rec.u32[0] = (rec.u32[0] & 0xffffc000) | (int)((h + 2048.0f) * 4.0f);
```
证据：解码 `0x140276244`–`0x140276265`、`0x140277ae8`–`0x140277b0e`；编码 `0x140276a07`–`0x140276a1d`（`addss 2048.0` → `mulss 4.0` → `cvttss2si` → `and $0xffffc000` → `or`）。

### 0.3 op（0…4）= 五个高度工具 **[代码]+[推断]**

`FUN_140276110` @`0x140276110` 共 **8 个参数**（4 寄存器 + 4 栈；入口是 3 字节 `mov rax,rsp`，objdump 会失步，见 §11.2）：

| # | 槽位 | 含义 |
|---|---|---|
| 1 | `rcx` → r13 | `Map*`（角点数组在 `+0x188`） |
| 2 | `edx` → r12d | **op（0…4 = 五个高度工具；其它值 → 不改高度，只走写回/标记）** |
| 3 | `r8d` → esi | **radius（角点格数）**：bbox = ±(radius−1)，掩码归一化半径 = radius−1 |
| 4 | `r9d` → edi | 形状标志：`useCircle = (r9d == 0) \|\| (op <= 1)` |
| 5 | `[rbp+0x130]` | `captureTargetFlag`：非 0 时把鼠标按下点角点高度写进 `[map+0xb94]` |
| 6 | `[rbp+0x138]` | `float* point`（世界坐标 2 个 float），喂给 `FUN_140263fb0` 求角点索引 |
| 7 | `[rbp+0x140]` | `reverseFlag`：op0/1 取负、op4 换用 Reverse 权重对 |
| 8 | `[rbp+0x148]` | 可空的"本笔画批次列表"（undo 容器，见 §0.6） |

`op` 判定：

```
0x140276876: test %r12d,%r12d ; js  0x140276a21   ; op<0 → 跳过高度计算（仍写回）
0x14027687f: cmp $1,%r12d     ; jle 0x14027697e   ; op 0 / 1  → cos 衰减的 ± 步进
0x140276889: cmp $2,%r12d     ; je  0x14027694e   ; op 2      → 把高度钳制到 [map+0xb94]
0x140276893: cmp $3,%r12d     ; je  0x1402768da   ; op 3      → 随机扰动
0x140276899: cmp $4,%r12d     ; jne 0x140276a21   ; op 4      → 3x3 加权平均（否则跳过）
```
（op ≥ 5 与 op < 0 都落到 `0x140276a21`：**不修改高度**，但记录仍被写回/标脏——这正是 5/6 水刷、7 斜坡刷复用同一入口的方式。）

| op | 语义（由算法形状判定） | 决定性证据 |
|---|---|---|
| 0 | +步进（升高） | `0x1402769a4` 不取负；步进含 `cos()` |
| 1 | −步进（降低） | `0x14027699e`–`0x1402769a4`：`cmp $1,%r12d` → `mulss -1.0f` |
| 2 | 钳制到目标高 `[map+0xb94]`（整平） | `0x14027694e` 起仅做 clamp+写回，无随机/无邻居 |
| 3 | 随机扰动（噪化） | `0x1402768da`–`0x140276907`：`rand(0,21)*6.4−64` |
| 4 | 3×3 加权平均（平滑） | 阶段一 `0x140276400`–`0x1402766eb` 用权重表 `0x1417bc528` |

**op → UI 功能名**：`0x14029acdd`–`0x14029acf3` 的分支把序号 **0/1/2/3/4** 依次映射到字符串
`WESTRING_BRUSH_RAISE`(@`0x1412e6ad0`)、`WESTRING_BRUSH_LOWER`(@`0x1412e6ae8`)、`WESTRING_BRUSH_PLATEAU`(@`0x1412e6b00`)、`WESTRING_BRUSH_NOISE`(@`0x1412e6b18`)、`WESTRING_BRUSH_SMOOTH`(@`0x1412e6b30`)。
即 **op0=升高地形、op1=降低地形、op2=整平地形、op3=噪化地形、op4=平滑地形**。
辅助证据：全图平滑操作 `0x140279b4c: mov $0x4,%edx` → `call 0x140276110`（随后弹 `WESTRING_SMOOTHINGHEIGHTS`，`0x140279a79`）；整平/崖层级驱动器 `0x140314cdc: mov $0x2,%edx`。
**[推断]** 该序号与 UI 按钮序号的数值相等（拖拽动作结构 `entry+0x18` 传给 `op`，`entry+0x10` 用于主工具分派：`0x14017c924`/`0x14017c92b`）。**严格确认方法**：在 `0x140276110` 下断点，逐个点按 5 个高度按钮读 `edx`。
> 与 `1.32-brush-water-texture-cliff.md` §0.5 的**命名冲突**说明：该文把 `op 0..4` 记作"悬崖层级 5 个按钮（降两级/降一级/同级/升一级/升两级）"，并把 `FUN_14026a480` 称作崖层级刷。两种读法的**分派事实一致**（`op==7→FUN_14027d450`（斜坡）、`op<=4→FUN_14026a480`、`5/6→FUN_140314880`（深/浅水），`0x14017c9c7`/`0x14017c9cd`/`0x14017c9a3`），分歧只在 `op 0..4` 的**功能命名**。本文依据 `FUN_140276110` 内的算法形状（±cos 步进 / 置目标 / 随机 / 3×3 平均）与 `WESTRING_BRUSH_*` 映射，判定 `op 0..4 = 五个高度刷`。注意 `FUN_14026a480` 并不直接改高度：它算 `[map+0xb98] = (corner[+0x0a]&0xf) + offset`（offset 随 op 取 −2/−1/0/+1/+2，`0x14026a4a3`–`0x14026a4b5` 区段），并**调用 `FUN_140277030` → §7 的圆盘扩散**（`0x14026ab52`）。

### 0.4 笔刷足印：bbox + 圆形掩码 **[代码]**

```c
// 鼠标点 -> 角点
idx = FUN_140263fb0(map, worldPos);        // 越界返回 -1（0xffffffff）
cx = idx % (w+1);  cy = idx / (w+1);

// bbox（0x140276272–0x1402762c8）
x0 = max(cx - radius + 1, 0);   x1 = min(cx + radius - 1, w);
y0 = max(cy - radius + 1, 0);   y1 = min(cy + radius - 1, h);

// 圆形掩码（0x140276837–0x140276870，五个 op 共用同一段）
d2 = (x-cx)^2 + (y-cy)^2;
d  = FUN_141173d48(d2);                    // = sqrtf（错误串 "sqrtf" @0x1414fa430）
if (radius > 1) d /= (float)(radius - 1);  // 归一化半径 = radius-1；radius==1 不做除法
if (useCircle && d > 1.0f) continue;       // comiss 1.0f；ja → 跳过该角点
```

- `useCircle` 的计算（`0x1402762f1`–`0x140276304`）：`useCircle = (shapeFlag == 0) || (op <= 1)`。
  即**升高/降低永远用圆形掩码**；整平/噪化/平滑由 `entry+0x08`（`shapeFlag`）决定是否用方形足印。
- `radius` = `entry+0x04`（`0x14017ca97`），足印 = `(2*radius-1)^2` 个角点；`radius=1` → 单角点，`radius=2` → 3×3 且只有中心与四正交邻居（(±1,±1) 的 d=√2>1 被裁掉）。
- **"步长随笔刷尺寸缩放"** 体现在 op0/1 的 `× radius`（见 §1）；op2/3/4 的幅度与 radius 无关。

### 0.5 高度钳制窗口（两个地方，公式不同！） **[代码]**

笔画内联钳制（op0/1/2/3/4 共用，`0x140276a07` 之前）：

```c
h = min(max(h, [map+0xbc8]), [map+0xbc4]);      // [0xbc8]=Terrain.MinHeight, [0xbc4]=Terrain.MaxHeight
```
证据：`0x1402768b8`/`0x1402768c6`（op4）、`0x140276927`/`0x14027693a`（op3）、`0x140276960`/`0x14027696e`（op2）、`0x1402769e9`/`0x1402769fc`（op0/1）。**这四处都是"直接用 MinHeight/MaxHeight"，不减层偏移**（见 §6.2 与之不一致的另一套公式）。

INI 装载（同一常量）：`Terrain.MaxHeight` → `[map+0xbc4]` 与 `[map+0x10c]`；`Terrain.MinHeight` → `[map+0xbc8]` 与 `[map+0x110]`；`Terrain.MaxSlope`（度）→ `[map+0xbcc]`，再 `tanf(deg*0.0174533)` → `[map+0xbd0]`。
证据：`0x140260c43`–`0x140260cad`（建图配置装载）、`0x140265f7b`–`0x140265fd6`（`FUN_140265f20` 重载）、`0x1402661c6`–`0x14026621e`（`FUN_1402661c0`）。`0x14118e8a0` = **`tanf`**：小参数分支 `x + x³·C`，`C = 0.3333333333333333`（@`0x1414fa688`，`0x14118e920`/`0x14118e928`），阈值 `π/4`（@`0x1414fa6c8`）—— 系数为正 1/3（而非 cos 的 −1/6）可判定它是 tan，**所以 `[map+0xbd0] = tan(MaxSlope)`**。
另 `[map+0xbd4] = (int)((MaxHeight + 256.0f) * 0.0078125)` = 层数（`0x140260cd5`–`0x140260cd9`）——即"高度域按 128 世界单位分层"的层数，MaxHeight=2560 时为 22。

### 0.6 公共写回与收尾 **[代码]**

每个角点算完新高度后（`0x1402768a3`–`0x140276a5f`）：

```c
recHeap.u32[0] = (recHeap.u32[0] & 0xffffc000) | (int)((h + 2048.0f) * 4.0f);
id = recHeap.u32[1] & 0x3ffff;                       // 角点线性索引（写回函数会断言）
bool ok = FUN_1403be230(map, id, &recHeap, batch, 3); // 唯一写回通道，第 5 参 flags=3（16 位）
FUN_140263b00(map, id, &blockVec, /*radius=*/0);      // 把 id 所属 4x4 块收进脏块向量
```
`FUN_1403be230` @`0x1403be230` 的真实签名 = `(Map*, int32 cornerIndex, const Rec28* src, Batch* batchOrNull, uint16 flags)`：

| 步骤 | 行为 | 证据 |
|---|---|---|
| 断言 | `src.u32[1] & 0x3ffff == cornerIndex`，否则 `FUN_141084490(0x57)` | `0x1403be261`–`0x1403be26e` |
| 变更检测 | `FUN_1403be720(map, realRec, src)` 逐字段比较（**忽略 `+0x0b`**，比较高度/水/纹理/层/法线等），全等 → 直接返回 0，不写、不标脏 | `0x1403be28e`；比较器 `0x1403be720`–`0x1403be928` |
| undo | `batchOrNull != 0` 时 new 一个 0x48 字节命令（vtable `0x141321fa0`，{vptr,map,旧记录28B,新记录28B}）并挂到批次上，**同角点只留一条（按 `cmd+0x14 & 0x3ffff` 合并）** | `0x1403be2ad`、`0x1403c19b0`、`0x1403c1c30` |
| 写回 | 复制整条 28 字节，**唯独保留数组里旧的 `+0x0b`** | `0x1403be2dc` → `0x1403be2e5`–`0x1403be305` |
| 标脏 | `FUN_140263b00(map, idx, &vec, 1)` 收块 → 每块 `block[+0x294] |= di`，其中 `di = (flags & 0x8017) ? flags|0x100 : flags`（flags=3 → `di=0x103`） | `0x1403be31c`–`0x1403be389` |
| 整行通知 | `di & 0x8014` 时通知 `[map+0xa78]`（flags=3 不触发） | `0x1403be39b`–`0x1403be3c5` |
| 收尾 | `[map+0xb88] = 1`（"地图已修改"） | `0x1403be3f5` |

`FUN_140263b00` @`0x140263b00` 的真实签名 = `(Map*, uint32 cornerIndex, vector<Block*>* out, int radius)`；它**不写任何角点字节**，只把该角点 ±(radius*128+1) 方形 4 角各自所属的 4×4 块指针**去重**后 push 进 `out`。
证据：世界坐标从角点自带的位域解出（`rec.u32[0]>>23` / `&0x7fc000`，`0x140263b7d`–`0x140263bcd`）、块索引 `(x-[map+0x100])*0.001953125` 对 `(w-1)>>2` 夹紧（`0x140263c30`–`0x140263cc0`）、块指针 `[map+0x1d0] + idx*0xFD8`（`0x140263cec`）。

- 脏块向量是**栈上局部对象** `{base, count, cap}`，初始内联容量 4（`0x140276748`–`0x14027675e`：`size=0, data=&stack, cap=0x8000000000000004`）。
- 第 8 参数 = **可空的本笔画"批次列表"**（容器 `{vptr, count@+8, data@+0x10, cap@+0x18}`）：非 0 时 `FUN_140276110` 先 new 一个 0x20 字节批次（vptr `0x1412e2c68`）并登记进该列表（`0x1402761cc`–`0x1402761f9`，追加函数 `0x140155f60`），随后把这个批次当 `batch` 传给 `FUN_1403be230`；**它不抛异常**（旧版 `1.32-dynamic-capture.md` 猜测的 "非 0 即 throw" 不成立）。
- 笔画结束（`0x140276aae`–`0x140276b2a`）依次：
  1. 对脏向量里每个块执行 **坡度修正** `FUN_140275e10(map, block, batch)`（`0x140276ace`，见 §6）；
  2. 把**全图**角点的 `+0x0b` 字节清零（`0x140276af0`–`0x140276b0d`）；
  3. `FUN_1402dd8b0(map, &blockVec, batch)`、`FUN_1402d9e70(map)`、`FUN_1402d7b40(map)`（`0x140276b1a`–`0x140276b2a`）——三者**都不改角点高度**：
     - `FUN_1402dd8b0` @`0x1402dd8b0`：对块集合求**世界包围盒并集**（每块 `block+0x280/+0x284` 起 `−128 … +512`，`FUN_1402de6a0`）并通知 `[map+0xa70]`/`[map+0xa78]`（`0x1401f0460`）；其第 3 参在函数体内从未被读。
     - `FUN_1402d9e70` @`0x1402d9e70`：`for (i < [map+0x450]) [map+0x458][i*0x108].u32[+4] |= 8`（另一套数组的批量失效位）。
     - `FUN_1402d7b40` @`0x1402d7b40`：`if ([map+0xa08]) 0x1403606b0(obj)` —— 用 `FUN_140277570(…,7)` 重算该对象顶点 Z（`+12.8f`）。
- 高度相关的**块级失效掩码**：`FUN_14027ce80(map, mask)` @`0x14027ce80` = 把 16 位掩码 OR 进每个 4×4 块的 `[block + 0x294]`（块步长 `0xFD8`、块数组 `[map+0x1d0]`、块数 `[map+0x1c8]`）。全图平滑/随机高度用 `mask = 0x8000`（`0x140279b6e`），其它工具用 `0x80`（`0x140167380` case 2/3/4，`0x140167649`）。**`+0x294` 各位的具体含义仍未知（见 §10 U11）。**
- 4×4 块 = 512×512 世界单位：`FUN_1402640b0` @`0x1402640b0`：`x0=[block+0x278]<<2, y0=[block+0x27c]<<2, x1=x0+4, y1=y0+4`（钳到 `[map+0xf4]/[map+0xf8]`）。

**`+0x0b` 标记协议**（防重复处理的 visited 位）：笔画开始时全图为 0（上一次笔画收尾清过）；写回函数**不修改**它；贴图类 op 会把它置 1（`0x14026a8ea`）；坡度修正 `FUN_140275e10` 跳过 `==1` 的角点，被修正过的角点置 2，递归层再置 `depth+1`；本次笔画结束再全图清 0。

> 与 `1.32-brush-water-texture-cliff.md` §0.6 的差异：该文把写回原语写成 4 参 `(map, idx, rec, flags)`、把 `3` 当第 3 参；实测是 **5 参，`3` 是第 5 参 flags，第 4 参是 undo 批次**。两文对"整条 28 字节写回、保留 `+0x0b`"的描述一致。

## 1. 升高地形 / 降低地形（Raise / Lower，op 0 / op 1）

### 对应功能
UI：**升高地形**（Raise）＝ op 0，**降低地形**（Lower）＝ op 1；字符串 `WESTRING_BRUSH_RAISE` @`0x1412e6ad0` / `WESTRING_BRUSH_LOWER` @`0x1412e6ae8`（序号映射 `0x14029acdd`）。任何 `useCircle=1`（两者恒为 1，`0x1402762f6`–`0x140276301`）。

### 算法（逐角点，`0x14027697e`–`0x1402769c8` 计算，`0x140276a07` 写回）**[代码]**

```c
float apply_raise_lower(int x, int y, int cx, int cy, int radius, int op, bool reverse)
{
    float d2 = (x-cx)*(x-cx) + (y-cy)*(y-cy);
    float d  = sqrtf(d2);                              // FUN_141173d48
    if (radius > 1) d /= (float)(radius - 1);
    if (d > 1.0f) return NAN;                          // 圆形掩码：直接跳过该角点
    float w = cosf(d * 3.14159f * 0.5f);               // 0x1411721f0 = cosf
    float step = w * (float)radius * 6.4f;             // ★ 步长 ∝ 笔刷尺寸
    if (op == 1) step = -step;                         // 降低
    if (reverse) step = -step;                         // 反向（右键/修饰键）
    float h = decode(corner.u32[0]) + step;
    h = clamp(h, [map+0xbc8], [map+0xbc4]);            // MinHeight / MaxHeight
    corner.u32[0] = (corner.u32[0] & 0xffffc000) | (int)((h + 2048.0f) * 4.0f);
}
```
要点：
1. **衰减曲线是余弦，不是查表**：`0x14027697e: mulss π; 0x140276983: mulss 0.5; 0x140276988: call 0x1411721f0`。`0x1411721f0` 是 MSVC 的 `cosf`：`|x| ≤ π/4` 时走 `1 − x²/2 + x⁴/24 − x⁶/720 + …` 分支（系数位于 `0x1415005d0`–`0x1415005f0`：−0.5、0.041666…、−0.001388…、2.480158…e−05、−2.75573…e−07，`0x141172440`–`0x141172490`）。因此 `w ∈ (0,1]`，中心 1、边缘 0。
2. **步长随笔刷尺寸线性放大**：`0x14027698d`–`0x140276999`：`step = cos(...) * (float)radius * 6.4f`。`radius=1` 时中心一次 +6.4 世界单位（编码后 raw +25，因为 6.4×4=25.6 被 `cvttss2si` 截断 ⇒ 实际 +6.25）。
3. **量化**：`(int)((h+2048)*4)` 向零截断，然后 OR 进 `rec & 0xffffc000`（bit14 以上=该角点 X/Y 序号，必须保留）。
4. 掩码是**硬边圆**（`d > 1` 直接跳过），圆内不再做二次权重；`radius` 同时决定足印半径与步长幅度，两者都用 `radius-1` 归一化 → 视觉上"刷子越大越高"。

### 常量
`6.4f`@`0x1412d02b8`；`π`@`0x1412c9718`；`0.5f`@`0x1412a0cbc`；`1.0f`@`0x1412a0cc4`；`−1.0f`@`0x1412a8a08`；`2048.0f`@`0x1412ca628`；`4.0f`@`0x1412e1f60`；`6144.0f`@`0x1412b3e14`。

### 内存写入
| 目标 | 内容 |
|---|---|
| 角点 `+0x00` bit0–13 | 新高度 raw；bit14–31（X/Y 序号）保留 |
| 角点 `+0x0b` | 本工具**不写**（写回函数刻意保留旧值；见 §0.6） |
| 角点其余字节 | 由写回函数整条复制（值不变） |

| 栈上脏块向量 + `[block+0x294]` | 经 `FUN_140263b00(map,idx,&vec,0)` 收集 4×4 块，再 `|= 0x103`（flags=3） |

### 证据（函数地址）

### 不确定项
- **衰减曲线是否与 1.27 完全一致**：1.32 这里是 `cos(d·π/2)·radius·6.4`；若需要与 1.27 逐位比对，必须在 1.27 二进制上重复本文 §1 的取指顺序（本文只证明 1.32）。
- `radius-1` 归一化在 `radius=1` 时被跳过（`d` 不归一化），此时圆形掩码等价于"单角点"；如果实际存在 radius=0 的调用，`radius > 1` 为假、足印 bbox 为 `[cx+1, cx-1]` 空集 → 无操作（未观测到 radius=0）。

**(b) 应用（`0x14027694e`–`0x14027697c`）** **[代码]**

## 3. 平滑地形（Smooth，op 4）

### 对应功能
UI：**平滑地形**（Smooth）＝ op 4；字符串 `WESTRING_BRUSH_SMOOTH` @`0x1412e6b30`。
同一 op4 也被"全图平滑"命令复用（`0x140279b4c`，见 §5）。

### 算法
两阶段：**阶段一**把足印内每个角点的平滑结果算进临时缓冲 `[map+0x2e8]`；**阶段二**逐角点从缓冲读值、钳制并写回。
两阶段都用同一段圆形掩码，且**没有任何距离衰减**（只有硬边圆）。

**阶段一（`0x140276376`–`0x1402766eb`）** **[代码]**

```c

```

**权重表 `0x1417bc528`（实测 9 个 float）** **[代码]**

```

      1, 2, 1 }        // Σ = 12，中心权重 = 0 → 中心点被排除在"邻居平均"之外
```

## 6. 笔画后处理管线：坡度钳制（flood fill）

### 6.1 触发与范围 **[代码]**

`FUN_140276110` 末尾对**每个脏 4×4 块**调用 `FUN_140275e10(map, block, batch)`（`0x140276ace`）。`FUN_140275e10` (入口 `0x140275e10`) 用 `FUN_1402640b0` 把块换算成图块矩形 `[x0,x0+4]×[y0,y0+4]`，然后逐角点：

```c
for (y = y0..y1) for (x = x0..x1) {              // 注意是闭区间
    if (corner(x,y).u8[0x0b] == 1) continue;     // 被本 op 直接写过的角点跳过
    float h = decode(corner.u32[0]);
    float lo, hi;
    FUN_140277a90(map, x, y, &lo, &hi);          // 允许高度窗口（§6.2）
    if (!(h < lo || h > hi)) continue;           // 未越界 → 不动
    float nv = (h < lo) ? lo : hi;
    rec.u32[0] = (rec.u32[0] & 0xffffc000) | (int)((nv + 2048.0f) * 4.0f);
    if (FUN_1403be230(map, rec.u32[1] & 0x3ffff, &rec, batch, 3)) {
        corner.u8[0x0b] = 2;                                 // 标记层级 = 2
        FUN_1403be070(map, x, y, nbr[9]);                    // 3x3 邻居指针
        for (dx = -1; dx <= 1; ++dx)
          for (dy = -1; dy <= 1; ++dy)
            if (!(dx == 0 && dy == 0) && nbr[3*(dx+1) + (dy+1)] != 0)
                FUN_140275c00(map, x+dx, y+dy, batch, /*depth=*/2);   // 递归扩散
    }
}
```
> 邻居数组索引：`FUN_1403be070(map, x, y, out)` 用**外层＝x 偏移**的循环，把 `out[3*(dx+1) + (dy+1)]` 写成角点 `(x+dx, y+dy)` 的指针（越界写 0），即 `out` 是**列主序**（x 步长 3、y 步长 1）。证据：`FUN_1403be070` `0x1403be070`–`0x1403be1b6`（`plVar4 += 3` 对应 x+1，三次写对应 y−1/y/y+1）。
`FUN_140275c00(map, x, y, batch, depth)`（入口 `0x140275c00`）与上段同形，差别是：
- 入口守卫 `if (corner[+0x0b] == 0 || depth < corner[+0x0b])`（`0x140275c52`–`0x140275c60`）→ 只有"未处理"或"更深层级"才处理；
- 已有值在窗口内时直接返回、不写（`0x140275cda` 处的"无变化就 return"）；
- 处理成功后把标记写成 `depth + 1`（`0x140275d5a`），再用 `depth+1` 递归 8 邻居（`0x140275db1`）。
⇒ 标记字节 `+0x0b` 就是"距本次改动的层级/环数"，修正按环向外扩散，层级单调递增，天然终止。
另一个入口 `FUN_140275ad0(map, vector<Block*>, batch)`（调用者 `FUN_1402807d0`）对每个块直接以 `depth = 1` 进入 `FUN_140275c00`，之后清全图 `+0x0b`。

### 6.2 允许高度窗口 `FUN_140277a90(map, x, y, &minOut, &maxOut)` **[代码]**

```c

float hi   = [map+0xbc4] - off;                           // MaxHeight
float lo   = [map+0xbc8] - off;                           // MinHeight
if (lo >= 0.0f) lo = 0.0f;                                // ★ 下界被"截到 ≤ 0"
if ([map+0xbcc] < 85.0f) {                                // ★ MaxSlope ≥ 85° 时完全不约束邻居（视为近垂直）
    FUN_1403be070(map, x, y, nbr[9]);                     // 列主序 nbr[3*dx+dy]；索引 0/1/2 ↔ 偏移 −1/0/+1
    for (dx = 0..2) for (dy = 0..2) if (nbr[3*dx+dy] != NULL) {
        step = tanMaxSlope * ((dx == 1 || dy == 1) ? 128.0f : 181.01888f);   // 正交 128、对角 181.01888
        float nh = decode(nbr.u32[0]);
        hi = min(hi, nh + step);        // 0x140277bad / 0x140277c58: minss
        lo = max(lo, nh - step);        // 0x140277bb1 / 0x140277c5c: maxss
    }
}
if (FUN_14013caa0(0x9a, 0)) {                              // 全局门（见下）
    float f = lo;
    if (FUN_140317b40(map, x, y, &tmp))      f = -64.0f;    // 0x140277c9f
    else if (FUN_140316620(map, x, y, &tmp)) f = -3.2f;     // 0x140277cc0
    lo = max(lo, f);                                       // 0x140277cc9
    if (lo > hi) hi = lo + 6.4f;                           // 0x140277cda
}
*minOut = min(lo, hi);   *maxOut = max(lo, hi);            // 0x140277ce2–0x140277cf5 保证 min ≤ max
```
- `tanMaxSlope = [map+0xbd0] = tanf(Terrain.MaxSlope · π/180)`（`tanf` 证据见 §0.5：`0x14118e8a0` 的小参数多项式系数为正 1/3）。因此**最大邻居高差 = 128·tan(MaxSlope)**（正交：`dx==1` 或 `dy==1`，含正上/正下）与 **128√2·tan(MaxSlope)**（四个对角）。步长选择在 `0x140277b79`（`cmovne` 在 `0x1412e32d4`(181.01888) 与 `0x1412b83d0`(128.0) 间选）与 `0x140277bd3`（中列硬编码 128.0）。
- `[map+0xbd0]` 的**唯一消费者**就是本函数（3 处引用：`0x140277b87`、`0x140277bd3`、`0x140277c2a`，全在 `FUN_140277a90` 内）。
- 门限 `85.0f`（`0x1412e32d0`，`0x140277b16`）：`comiss 85.0, [0xbcc]` + `jbe` 跳过邻居循环 ⇒ **邻居约束仅在 `MaxSlope < 85°` 时生效**；85° 是"视为垂直、不限制"的哨兵值。
- 全局门 `FUN_14013caa0(0x9a, 0)`（`0x140277c75`）：一个"编辑器/游戏状态允许"查询，为真时才叠加 −64.0/−3.2 两个附加下界与 `+6.4` 兜底。
- `FUN_140317b40(map,x,y,&h)`（`0x140317b40`）= 该角点 `+0x0c` 字节 bit4 置位（有水/崖类标志）时返回真并给出 `u32[+4]>>18` 解码的高度；`FUN_140316620` 是它的 3×3 邻域版本（**±1 环内**任意一点满足即真）。即"紧邻崖/水"时下界额外降到 −64、邻环降到 −3.2。
- 输出恒为 `(min, max)` 有序对；`+6.4` 只在 `lo > hi`（窗口被压翻）时兜底撑开 6.4。**[代码]**：`0x140277cd2` 的 `comiss/jbe`、`0x140277ce7` 与 `0x140277cf1` 的两对 `movss` 覆盖了全部三条出口，伪 C 里"先写后覆盖"的 `if (fVar4 < fVar7)` 是反编译伪影。

## 7. 另一条高度后处理：绝对越界圆盘扩散（区域/命令路径，**不属于笔画**）

**[代码]**，由 `1.32-brush-heights` 的专项子分析 + 本文复核（`0x140276d50`–`0x140276f30` 逐条看过）。

### 7.1 触发链
| 调用链 | 说明 |
|---|---|
| `FUN_14026a480`(`0x14026ab52`) → `FUN_140277030(map, vector<Block*>, observer)` → **`FUN_140276c70(map,x,y,observer)`** | 区域（矩形/整块）命令路径；`FUN_14026a480` 正是 §5 里写"自动纹理层 `[map+0xb98]`"的那个函数 |
| `FUN_14026cb50`(`0x14026cbca`) → `FUN_140277030` | 另一条区域命令 |
| `FUN_140276bc0(map)` → `FUN_140276c70` | **全图**外壳（遍历全部块）。**无任何调用者**（无 call、无 lea 取址）→ **[推断]** 1.32.10 里是死代码 |
| `FUN_140275ad0` → `FUN_140275c00(depth=1)` | 区域修正入口（走 §6 的递归版） |

**`FUN_140276110`（笔刷）从不调用 `FUN_140276c70`**：笔刷路径的坡度约束只有 §6 那一套。

### 7.2 算法 `FUN_140276c70(map, x, y, observer)`

```c
Corner* c = &CORNER(map, x, y);
float h  = getHeight(c, 7);                   // FUN_1403bde90(c, 7)
float hi = [map+0xbc4];                       // MaxHeight（不减层偏移）
float lo = min([map+0xbc8], -256.0f);         // MinHeight 与 -256 取小
if (lo <= h && h <= hi) return;               // 未越界 → 直接返回
float delta = ((h > hi) ? hi : lo) - h;       // 越界量（带符号）
if (fabsf(delta) < 2.3841858e-07f) return;    // 2^-23（0x1412b4814）
float r = fabsf(delta) / tanf(0.5235988f);    // ★ 硬编码 30°（π/6 @0x1412e32c8）
int   n = 2 + (int)(r / 128.0f);              // 影响范围（角点格数）
writeCorner(c, clamp(h, lo, hi));             // 越界点本身先夹回窗口内
for (int dy = -n; dy <= n; ++dy)
  for (int dx = -n; dx <= n; ++dx) {
    if (x+dx > w || y+dy > h) continue;
    float d = 128.0f * sqrtf(dx*dx + dy*dy);
    if (d / r > 1.0f) continue;                            // 圆形范围
    float wgt = delta * 0.5f * (1.0f + cosf(3.14159f * 0.5f * (d / r)));
    //         中心 = delta，边缘 = delta/2
    float hnb = getHeight(nb, 7);
    if (!(hnb > wgt + hi || hnb < wgt + lo)) continue;      // 见 §7.3 守卫
    writeCorner(nb, hnb + wgt);
  }
```
写入统一走 `FUN_1403be230(map, corner[+4]&0x3ffff, &rec, observer, 3)`（`0x140276f73`）。

### 7.3 常量与实现细节
- 半径用**硬编码 30°**：`tanf(π/6)`，`π/6 = 0.5235988f`@`0x1412e32c8`（`0x140276d61` → `call 0x14118e8a0` → `0x140276d6e divss`）。**与 `[map+0xbd0]`（Terrain.MaxSlope 的 tan）无关** —— 这是与 §6 最重要区别。
- 核形状：`0.5·(1 + cos(π/2 · d/r))`（`0x140276e7c`×0.5、`0x140276e81`×π、`0x140276e86` cosf、`0x140276e94` +1.0、`0x140276eb1` ×delta）。**中心拿满 `delta`、边缘只拿 `delta/2`**（不是 0 → 见 §10 不确定项）。
- 范围 `n = 2 + (int)(r/128)`（`0x140276d81` `mulss -0.0078125` = −1/128、`0x140276d89` `cvttss2si`、`sub %eax,%r15d` 且 r15d 初值 2）。
- **应用守卫（反直觉）**：`apply ⟺ (h_nb > w+hi) || (h_nb < w+lo)`（`0x140276ecd`–`0x140276ee2`）⇒ 只有"加完之后仍会越界"的邻居才被加；落在 `[lo+w, hi+w]` 带内的邻居**不动**。这是原代码事实，是否为有意设计无法从静态代码判定。
- 未越界时 `hi/lo` 与 §6 不同：这里 `lo = min(MinHeight, −256.0f)`（`0x140276cda` `minss -256.0f`@`0x1412d460c`），且**不减层偏移**。

## 11. 反编译/反汇编不可靠之处（必须注意）

1. **`FUN_140276110` 的 Ghidra 伪 C 是残缺的**：`FUN_141173d48`（实为 `sqrtf`）被 Ghidra 判成 `Subroutine does not return`（`1.32-decomp-dump.txt` 第 121/143 行等处），于是"逐角点应用"整段消失，只剩 bbox 与分派。**本文的算法全部来自原始反汇编**（`/tmp/we_asm.txt`），不是伪 C。
2. **objdump 在若干函数入口处失步**：真入口是 3 字节的 `48 8b c4 (mov rax,rsp)`，`/tmp/we_asm.txt` 把入口前 3 字节解成垃圾后再重新对齐（例：`FUN_140276110` @`0x140276110`、`FUN_140275e10` @`0x140275e10`、`FUN_1402d9e70`、`FUN_1402d7b40`）。因此：**函数体本身大体可用，但栈参数槽位必须以真入口的 `lea rbp,[rax-0x108]` + push 数推算**——`FUN_140276110` 是 7 个 push ⇒ 第 5/6/7/8 参在 `[rbp+0x130]/[rbp+0x138]/[rbp+0x140]/[rbp+0x148]`。这几处（含 `FUN_1402d9e70`、`FUN_1402d7b40`，见 §0.6）需要从文件字节重新反汇编才能看清。
3. **本镜像 `.pdata` 把同一函数切成多个碎片条目**（例：`0x1402dd8b0` size=9 后紧跟 `0x1402dd8b9` size=61…；`0x1403be418/0x1403be420` 亦然）。**不要用 `.pdata` 的 EndAddress 当函数长度**，本文所有范围都按 `ret`/`int3` 实测。
4. **`FUN_14017c850`（拖拽分派）伪 C 大面积损坏**：Ghidra 明确报 `Instruction at (ram,0x14017cd48) overlaps instruction at (ram,0x14017cd46)`、`Control flow encountered bad instruction data`、`halt_baddata()`（`gh_brush.txt` 第 8–49、207–255 行），jump table 索引把 `(int)entry+0x00` 渲染成 `switch(*param_2)` 的浮点 case。请只看反汇编。
5. **`FUN_1402797a0` / `FUN_140279bb0` 边界被切错**：Ghidra 给 `FUN_1402797a0` 的 size=785（到 `0x140279ab1`），但 `0x140279ab1`–`0x140279baa` 仍是同一函数的代码（"随机化/平滑高度"对话框逻辑 + 全图平滑循环 + 收尾），并以 `int3` 结束于 `0x140279bab`（`0x140279bab: int3`）。伪 C 里把尾部渲染成 `FUN_1401557c0("WESTRING_SMOOTHINGHEIGHTS",…)` 的"不返回调用"，从而截断。
6. **`if (fVar4 < fVar7) … LAB_140277cf1` 的伪 C 是误导**：`FUN_140277a90` 的尾部在反汇编里（`0x140277cd2`–`0x140277cf5`）是 `comiss/jbe` 加两对 `movss`，输出恒为有序的 `(min,max)`；伪 C 的"先写后覆盖"不是真实行为。
7. `FUN_140276110` 中 `0x1402764f3`–`0x140276611` 的**向量化 3×3 路径不可达**：进入条件是 `(col_end − col_start + 1) >= 4`（`0x1402764e9: cmp $0x4,%rax; jl`），而 3×3 邻域最多 3 列，故只有标量路径（`0x140276615`–`0x140276685`）会执行。不要按向量路径推导 4 列权重。
8. `FUN_140155f60` 不是"抛异常"：它是"把指针 push 进 `(容器+8)` 的 vector"（`0x140155f6d`、`0x140155f97`）。旧文档据 vtable `0x1412e2c68` 猜成异常对象是错的；该 0x20 字节对象是**本笔画的 undo 批次**。
9. `0x1412e32cc` 处的 `1.001f` 等常量只在插值把 `t` 夹到 `[0,1]` 的守卫里（`0x1402778c2`、`0x1402778dd`），与高度刷无关。
10. `2.3841858e-07f`（`0x1412b4814`，2^-23）与 `-256.0f`（`0x1412d460c`）只在 §7 的圆盘扩散里用；`-1/128`（`0x1412e2d40`）是范围换算。
