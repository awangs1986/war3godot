## 1. 通用掩码（所有笔刷共用）

```
圆: 设 R = size − 1
    对包围盒 [cx−R, cx+R] × [cy−R, cy+R] 内每个角点：
       if (dist² / (R²) ) <= 1.0f  ⇒  在掩码内
方形: 整个包围盒内全在掩码内
```
- **等级**：B（1.27 `0x603f89–0x603fa9` 水、`0x57e700` 高度）；官方 Reforged 版：**部分验证**（坡道 3×3/3 共线与 size−1 一致 ✓A；圆半径未单独测 ✗）
- **注意**：`size == 1` 时 R = 0 ⇒ 只有中心角点 ✓

### 1.1 各笔刷的掩码特例

| 笔刷 | 掩码 |
|---|---|
| 抬升 / 降低 | **恒为圆**（1.27 里 `param_3` 被强制置圆，B） |
| 整平 / 平滑 / 压平 | 圆或方（由形状参数决定） |
| 水 | 圆或方；**方形时整框都落笔** |
| 悬崖 | 圆（`0x574470`） |
| 坡道 / 纹理 / 边界 | 不是掩码笔刷：**角点集**由坡道规则或落笔集合决定 |

| 模式 | 行为 | 等级 |
|---|---|---|
| 抬升/降低 | 圆内每角点高度 ± 步长；**恒为圆** | B |

## 3. 水笔刷（浅水 / 深水）

```
1. 依次判断：如果该角点无水 ⇒ dL = (浅水 ? −2 : −1)        ← 1.27 分支实测，B
2. 如果该角点已有水 ⇒ dL = floor((waterWorld − groundWorld) / 128)   ← 按水位差
3. 在圆/方掩码内：置 bit4（water）、写水位 raw = (world+2048)*4
4. 然后依次调用：
     整平( size + 2 )        ← 关键：+2
     悬崖( size )            ← 关键：不加
```
- **等级**：B（1.27 `FUN_00603cc0`，`0x604068` / `0x60408a`）；官方 Reforged 版：**未验证**（缺尺寸分离实验）
- **深水重刷的实测现象（官方 Reforged 版 A）**：对**已有深水**的角点重刷 ⇒ 只在**南侧**扩出 5 点「water+层压到 0」+ 7 点「cliffType 15→1」，**不是对称圆** ⇒ 与"掩码 + size+2/size"组合尚不能完全解释 ✗
- **已知坑**：我曾把 `size+2` 加到 **cliff** 上 ⇒ 结果更差 ✗（正确是 plateau +2）

## 4. 悬崖笔刷（5 个模式）

### 4.1 dL 表（B，1.27 `FUN_00574a50`）

| 模式（= 面板按钮序） | dL |
|---|---|
| 0 降低两层 | **−2** |
| 1 降低一层 | **−1** |
| 2 同层整平 | **0** |
| 3 升高一层 | **+1** |
| 4 升高两层 | **+2** |

官方 Reforged 版核对：`base → P_c+2_s3_x3`（连点 3 次）共 **+6** ⇒ 每次 +2 ⇒ **模式 4 = +2 成立** ✓A

### 4.2 单次传播（B，1.27 `FUN_00574470`）

```
Ltar = curL + dL
对掩码内每个角点 (x,y)：
   Ltar' = clamp 到 [0, maxLayer]
   Ltar'' = max(waterLimit(x,y), min(Ltar', maxLayer))     ← 有水的点会被水位压低
   if (oldL != Ltar'' || oldMode != mode)：
        写 L、写 mode（记录字节 +0x0a = 低4位|mode<<4）、随机化变体
        记录变更
        → 并对该点的 3×3 邻域（除中心）**全部写同一 mode**      ← 这是 ct 圈更宽的原因
循环结束后：统计改动区旧层直方图取众数，再做一趟 5×5→3×3 一致性修复
```

- **等级**：B；官方 Reforged 版：**部分验证** — `ct 圈到 r≈6 而 L 圈到 r≈4.5`（A ✓）与"3×3 扩 mode + 后处理"的解释**一致** ✓
- **待定量化**：官方 Reforged 版的 L 辐射剖面实测为 **8 / 6 / 4**（每外一环 −2 层）⇒ 需要"邻居夹取 + 圆掩码 + size"三者的具体数值才能复现 ✗

## 5. 坡道笔刷（最容易错的一支）

### 5.1 写入判定（B，1.27 `FUN_00583310`）

```
前置：该角点必须是"层变化处"（三邻 (x+1,y)(x,y+1)(x+1,y+1) 任一不同）
方向：用 **浮点游标**相对角点的半格偏移（半格 = 64 世界单位）决定采样方向
情形：
  单轴有差              ⇒ 候选 = 3 点共线（×0,×1,×2）
  两轴都有差            ⇒ 若"对角层 == 中心层" ⇒ **直接返回，什么都不做**
                          否则候选 = 3×3 共 9 点
闸门：候选点的 (maxL − minL) 必须 **< 2**，否则整笔不生效
写入：目标标志值（0=清除 / 1=置位）由修饰键决定（Shift = 清除）
回滚：写完重算几何，失败则逐点把标志改回
```

### 5.2 写完后的自动清理（B，1.27 `FUN_00584270` + `FUN_00584600`/`0x584c00`）

```
对改动区内每个角点：
   if (有 ramp 标志) 且 (其 2×2 单元格四角中不存在 分类为 'R' 或 'S' 的格)
        ⇒ 清掉 ramp 标志
```
**格分类（`FUN_00584600`）**：

| 条件 | 字符 |
|---|---|
| 无 ramp 位、不斜 | `'A'` |
| 无 ramp 位、斜 | `'B'` |
| 有 ramp 位、斜 | `'H'` |
| 有 ramp 位、朝向 0 | `'L'` |
| 有 ramp 位、**仅单轴有差且层差 ≤ 1** | **`'R'`**（有效）|
| 有 ramp 位、**两轴都有差 或 九格全平** | **`'S'`**（有效）|
| 有 ramp 位、层差 > 1 | `'!'`（无效）|

### 5.3 官方 Reforged 版核对

| 结论 | 证据 | 判定 |
|---|---|---|
| 对角 +1 / +2 ⇒ 9 点 | `RampSweep`、`Y10_step_c2 → Y10_ramp_made` | ✓A |
| 四邻 +1（无对角更高）⇒ 3 点 | `R1 / R3 / NP2` | ✓A |
| 平地单击 ⇒ 0 点 | `flat-ramp` | ✓A |
| Shift 落笔 ⇒ 清除 | `RampSweep` vs `RampShiftRemove` | ✓A |
| 4 个亚格偏移集合相同 | `ramp_single_*` 4 组 | ✓A（同层时） |
| 3D 视图 Shift 移除 | `ramp-3d.json`（`ok:true`） | ✓A |

## 6. 纹理笔刷

## 9. 实现清单（照这个顺序改）

1. **掩码统一**：`R = size−1`、`dist² ≤ R²`、方形整框；抬升/降低强制圆
2. **高度笔刷**：抬升/降低/整平先按 1.27 结构实现（B 级可参考），**平滑先留空**（等实验）
3. **悬崖**：dL 表 + 邻居夹取 + 水位限层 + **3×3 扩 mode** + **5×5→3×3 修复**
4. **水**：掩码置 bit4 + 水位编码 + **整平 size+2 / 悬崖 size**
5. **坡道**：层差闸门 + 单轴/双轴 + 对角判定 + **浮点游标采样** + **R/S 校验后清位**
6. **纹理**：索引查表 + 变体 bits5–9 + 同函数处理 blight
7. **边界**：bit6 置/清

# 11. 悬崖传播的**最终数值模型**（A 级官方字节，`p0-5-cliff-propagate.md`）

## 11.1 结构（三个互相独立的层）
