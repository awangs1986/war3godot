# 传播函数反编译结果（REA，2026-10-16）

> 目标：解释 `known-differences.json` 里 `cliff_repeat` 那 20 点（4 L + 16 ct）差异的机制。
> 证据：`World Editor.exe` 1.32.10.18820 反编译（Ghidra，`/tmp/gh_prop.txt`、`/tmp/gh_c5.txt`）。

## 1. 结论：官方"传播"是**只传播悬崖类型**，不是层夹取

```c
// FUN_14026c810(map, ?, undoBatch)  —— 传播入口（矩形扫描，x 外层 y 内层）
for (x = x0; x <= x1; x++)
  for (y = y0; y <= y1; y++) {
    corner = base + ((width+1)*y + x)*0x1c;
    if (corner[0xb] != 0) {                 // 只处理"被标记过"的角点（+0x0b = 深度/命中标记）
      type = corner[10] >> 4;               // 源角点的悬崖类型（+0x0a 高 4 位）
      for (bx = x-1; bx <= x; bx++)         // ★ 2×2 块扫描（不是 8 邻环）
        for (by = y-1; by <= y; by++)
          if (in-bounds && FUN_14026e050(map,bx,by))   // ★ 额外空间门（分块/归属判定）
            for (块内 2×2 的每个 c2)
              if ((c2[0xb]==0 || depth < c2[0xb]) && (c2[10]>>4) != type) {
                c2[10] = (c2[10] & 0xf) | (type << 4);   // ★★ 只改类型，层不变
                c2[0xb] = depth+1;
                FUN_14026c5c0(map, c2x, c2y, batch, depth+1);   // 递归（深度单调终止）
              }
    }
  }

// FUN_14026c5c0(map, x, y, batch, depth) —— 递归体（结构与入口一致）
```

要点：

1. **只写类型**：`c2[10] = (c2[10] & 0xf) | (type << 4)` —— 低 4 位（层）**保持不变** ✓
2. **扫描形状**：2×2 块（`x−1..x` × `y−1..y`，再取块内 2×2）—— **不是 8 邻环**
3. **额外门 `FUN_14026e050(map,x,y)`**：只对满足该条件的角点传播（疑为分块/归属判定，待确认）
4. **终止**：靠 `+0x0b` 深度标记单调递增（`depth < c2[0xb]` 才继续），与实现一致 ✓
5. `FUN_1403be230`（写回原语）带的第 5 参 = `0x8000`（与笔刷直接写的 flags 不同）✓

## 2. 与实现的差异（这正是那 20 点的来源）

| 项 | 实现（`TerrainBrush.Propagate`） | 官方 |
|---|---|---|
| 传播内容 | **层**夹到 `[L−2, L+2]` | **只传播类型**（层不变） |
| 驱动来源 | 足印外圈起步（或从改动点） | 被标记角点（`+0x0b != 0`）+ 矩形扫描 |
| 邻域形状 | 8 邻环 | **2×2 块** |
| 额外门 | 无 | `FUN_14026e050(map,x,y)` |
| 层变化来源 | 由该传播产生 | **另有一条"笔画后处理"负责层一致性**（`FUN_140275e10`/`FUN_140277a90` 一类的 ±2 窗口 + 递归，见 `1.32-brush-heights.md` §6） |

→ 实验结果与此**部分**吻合（**尚未闭合**）：
- 单击 = 13 点改层（足印）+ **24 点只改 ct**（与"类型传播"一致）✓
- 连点后外环出现**层**变化 —— 该函数**不改层**，因此这部分**必须由另一条"笔画后处理"解释**，
  而那条链路（函数、调用点、顺序）**尚未定位**；`FUN_14026e050` 空间门、矩形范围来源也未确定
⇒ 只能说"类型传播的语义已定位"，**不能**说"20 点差异已解释"（4 处 L 差异仍未归因）。
