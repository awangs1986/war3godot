## 2. 已完成的 13 条规则（可直接实现）

| # | 规则 | 证据 |
|---|---|---|
| 1 | 层高→世界：`(raw & 0x3fff) << 9 − 6144`；1 层 = **128** 世界单位 | 双版本常量 `6144.0` / `128.0f` |
| 2 | **足印 = 欧氏 `r ≤ size−1`**；改动 = 足印 ∪ 3×3 膨胀（膨胀只写 ct） | 4 张存档零误差（见 §3） |
| 3 | 尺寸→点数：`1⇒1+8=9`、`3⇒13+24=37`、`5⇒49+40=89`、`8⇒149+64=213` | 同上 |
| 4 | 悬崖 dL 表 `0/1/2/3/4 ⇒ −2/−1/0/+1/+2`，`\|dL\|>2` 非法 | `ghidra_26a480.c` **L109-130** |
| 5 | 每点写后 **3×3 跳中心**传播 mode | `26a480.c` **L230-240** |
| 6 | 变体 = bits 5–9，**取值 0..3**（`FUN_14014e6a0(0,3)`） | `26a480.c` **L220** + 52 次写入只见 {1,2} |
| 7 | 水位限层：`L0 − (2 − (ground − (water+h0)) × 1/128)`，负则 0 | `26a480.c` **L196-201** + 常量 `1/128` 实测 |
| 8 | 水：置 **bit4**；水位 `raw = (world + 2048) × 4` | `314880.c` **L62** |
| 9 | 水 dL：无水 `5⇒−2`／`6⇒−1`；有水 `(水面−地面)/128` **向下取整** | `314880.c` **L68-84**，系数常量 `0x1412B83C8 = 0.0078125` |
| 10 | 水：随后 **整平尺寸 `size+2`**（半径 `size+1`）、**悬崖尺寸 `size`**（半径 `size−1`） | `314880.c` **L181/L187** + `276110.c` **L89/L190** |
| 11 | 平滑 = **加权平均 0.800 / 0.200**（Shift 变体 1.00 / 0.05） | 官方字节反解（`8192→8217→8212`） |
| 12 | 坡道：单轴差⇒**3 点共线**；双轴差且对角≠中心⇒**9 点（3×3）**；对角==中心⇒**不写** | `RampSweep` / `flat-ramp` 等 A 级 |
| 13 | 边界：置/清 w3e byte4 bit7，各 **1 点**、对称 | `C0→C1→C2` |

### 2.1 三种掩码半径（易混，务必分清）

## 7. GUI 实验的前提（当前卡点，勿重复踩）

官方 Reforged 的 **保存链** 在自动化下反复失败，已定位：

| 现象 | 根因 | 现状 |
|---|---|---|
| `WM_COMMAND(id=5)` 无反应 | Reforged 文件菜单**不经 WM_COMMAND** | 改 `Ctrl+S` ✓ |
| 另存为填不进名字 | 是 **Vista 标准对话框**（`DirectUIHWND`）⇒ `WM_SETTEXT` 无效 | 需**真实鼠标点击** + 键盘输入 ✓ |
| 文件被存成 `D：、tools、嗯新品、…` | **IME 把 `\`→`、`、`:`→`：`** | 只输入 **纯 ASCII 文件名** ✓（截图已验证填对） |
| 点保存无反应 | 我读到的控件 rect 与真实对话框**不一致**（真实约 1280 宽） | 需按**截图坐标**点击 ✗ 未打通 |
| `Ctrl+N`+Enter 得到的不是空白图 | 实际加载了**模板地图** | 需显式选尺寸/瓦片集 |

⇒ **A 组每项都卡在这一步** ✗；打通后每项约 1 分钟。
