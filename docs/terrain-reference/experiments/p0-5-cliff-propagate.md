## 5. 尚未定出的机制（下一轮）

对以下模型组合逐一评分（目标 = 官方 85 点）：

| 模型 | 结果 |
|---|---|
| 现实现（包围盒外圈起步 + 递归 + `d<s` 守卫） | 20 失配 |
| 从改动点向外推（递归） | 20 失配（与实现等价） |
| 只推一步 | 35+48 失配（过少） |
| 遍历顺序（x/y 外内、邻居升降序、守卫 `d≤s`） | 20 失配（**顺序无影响**） |
| 逐遍扫描（Gauss-Seidel，1..4 遍 × 4 种顺序 × 抬/压） | 20 失配（无影响） |
| 每点击多跑几遍传播 | 20 失配（无影响） |

**观察**：第二个实验（点击点 (32,30)，块内偏移 (0,2)）的上下不对称点有 **14 个且方向混合**
（有的 +y 高、有的 −y 高）→ 官方前缘是**不规则阶梯状**（图遍历式、带深度标记），
不是简单方向偏置，也不是干净的同心环。下一步应直接反编译**传播函数的遍历结构**
（`FUN_14026a480` 的调用链 / `0x573950` 系列），而不是继续在外层模型上试错。
