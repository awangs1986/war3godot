# P0-1 同角点重复施加（已完成，官方字节）

> 执行时间：2026-10-16 · 编辑器 1.32.10.18820（本机 Proton）· 基准图 `X1_base`（65×65，tileset `L`，悬崖 tileset `CLdi`/`CLgr`）
> 输入记录：`inputs/exp1_log.json` · 存档：`~/w3_blackbox/maps/X1_*.w3m` · 截图：`/tmp/exp/shot_X1_*.png`

## 方法

在平坦基准图上用**升高、尺寸 1、圆形**（每格 1 个角点 = +6.4 世界单位），对同一角点做 4 种操作，每步保存地图后抽取 `war3map.w3e` 逐字段差分：

| 步 | 操作 | 记录 |
|---|---|---|
| ① | 单击一次（按下 80ms） | `X1_h_click1` |
| ② | 同点按住 2 秒（单次按下-抬起） | `X1_h_hold2s` |
| ③ | 按下后在**同角点内**抖动 ±2px（9 次移动） | `X1_h_jitter` |
| ④ | 中心 → 邻格 → 中心（3 次单击；实测三次都落在同一角点） | `X1_h_roundtrip` |

基准恢复校验：撤销后重存 `X1_restore` 与 `X1_base` 差分 **0 点** ✓（保证后续实验可信）

## 结果（角点 (31,32) 的地面高度 raw）

| 操作 | h 变化 | Δraw | 结论 |
|---|---|---|---|
| 单击一次 | 8192 → 8217 | **+25** | 1 次按下 = **1 次施加** |
| 同点按住 2 秒 | 8192 → 8217 | **+25** | **按住不会连续施加**（无逐帧连发） |
| 同角点内抖动 ±2px | 8192 → 8217 | **+25** | 抖动不产生额外施加 |
| 3 次单击（同角点） | 8192 → 8267 | **+75 = 3×25** | **重复点击会累加**（每次各施加一次） |

## 对实现的含义

- 实现的「`Apply()` = 一次官方完整施加」模型 ✓ **有官方字节支持**（单击/按住/抖动均只 +1 次；重复点击线性累加）。
- +25 raw = `trunc((6.4+2048)·4) − 8192` ✓ 与实现 `StepWorld=6.4f` 的行为断言一致。
- 拖拽（按下后移动）**不**按帧累加：见 `p0-5-cliff-propagate.md` 的拖动实验（沿路径只出现一级层变化）。
