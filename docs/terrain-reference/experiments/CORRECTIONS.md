## 0. 根因：我把字段解码搞错了

权威字段表（v11，每角点 7 字节，零起始偏移）：

| 偏移 | 字段 |
|---|---|
| 0–1 | 地面高度 |
| 2–3 | 水面高度（低 14 位）+ 地图边缘位 `0x4000` |
| 4 | **低 4 位纹理索引**；`0x10` 坡道 / `0x20` **荒芜** / `0x40` 水 / `0x80` **边界** |

（`tf & 0x0F` 纹理、`0x10` ramp、`0x20` blight、`0x40` water、`0x80` boundary；

```

(35,30) cliffType 15 → 1
(33,31) tex       0 → 3      ← 实际画的是「纹理 3」
(33,31) groundVar 0 → 12
(34,31) layer     2 → 0
...
```

`D3→D6` 仅 2 条：`(34,31) tex 0→3`、`(34,31) groundVar 8→2` ✗ 同样与荒芜无关。

**因此**：
- 旧结论「荒芜位 = byte5 bit2+bit3」**作废**（那是地表变体）✗
- 旧结论「异纹理覆盖清除荒芜」**作废**（从未测到荒芜）✗

## 2. 修正：G5 边界统计（混入了层级/类型/变体）

**旧表述**（错误）：「放置 9 点 / 移除 7 点 / 交集 4 ⇒ 不对称」✗ —— 那是**把全部字段差异都算成了边界变化**。

**重解码后的正确结果**：

```
python tools/w3e_diff.py C0.w3e C1.w3e
# 差异条目 17（每条 = 一个角点的一个字段）
(33, 30) boundary       False → True     ← 唯一的 boundary 变化
其余 16 条为 cliffVar / cliffType / layer（前一次悬崖点击的残留，与边界无关）

python tools/w3e_diff.py C1.w3e C2.w3e
# 差异条目 10
(33, 30) boundary       True → False     ← 唯一的 boundary 变化
其余 9 条为 cliffVar / cliffType / layer
```

**新结论（A 级）**：
- 放置边界：**改 1 个角点**的 boundary（`False→True`），位置 `(33,30)`
- 移除边界：**改 1 个角点**的 boundary（`True→False`），**同一角点**
- ⇒ **放置与移除对称** ✓（旧"不对称"结论作废）
- 边界操作**不写** layer / cliffType / cliffVar / tex（本实验中的此类差异均来自其它笔画）✓
