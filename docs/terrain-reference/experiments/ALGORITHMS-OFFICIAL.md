## 1. 悬崖连点（`cliff_repeat`）

**A 级来源**：`fixtures/base.w3e → fixtures/P_c+2_s3_x3.w3e`，点击角点 **(31,29)**，`L:2 ct:15`，连点 3 次

### 1.1 实测：层级辐射剖面（中心 L=2 → 8，共 +6，即每次 +2 层）

| 到点击点距离 | 最终 L | 备注 |
|---|---|---|
| 0 | **8** | 中心 |
| 1.00（4 邻） | **8** | |

| 2.00（轴向隔一格） | **8** | |

⇒ **规则（A）**：每向外一环，L 比内环**低 2 层**；有效半径 ≈ **4.5 角点**；`cliffType 15→1` 覆盖到 **r≈6**

### 1.2 实测：**+y 方向不对称**（关键未解点）

| 点 | 距离 | 该环其余点 | 该点异常 |
|---|---|---|---|
| (31,33) | d=4.00 | 4 | **6**（高 2 层） |

⇒ 效应在 **+y（南）方向延伸更远** ✗。**同一异常在深水重刷也出现**（见 §2）⇒ 怀疑是**一个共同成因**，不是笔刷各自的 bug ✓

### 1.3 未解点

1. `+y` 方向更远的成因（可能是坐标/形状中心偏移，也可能是官方对 `(x,y)` 的方向约定）
2. 单次「升高一层」与「升高两层」是否都按 +2 层推进（本 case 是 3 次共 +6，未分离单次增量）
3. `cliffVar` 的随机分布（实测 0→1/0→2，分布规律未测）

## 2. 深水重刷（`deep`）

**A 级来源**：`fixtures/Y7_dp1.w3e → fixtures/Y7_dp2.w3e`，点击角点 **(31,32)**，点前状态 `L=0 water=True wh=8192`（**已是深水**）

### 2.1 实测：12 个变化点（全部在 **dy ≥ +1**，即全在点击点南侧）

| 相对坐标 | 变化 | 点前状态 |
|---|---|---|
| (−2,+1) (+2,+1) (−1,+2) (+1,+2) (0,+3) | **water False→True 且 L 2→0** | L=2, water=F, wh=8192 |
| (−3,+2) (+3,+2) (−2,+3) (+2,+3) (−1,+4) (0,+4) (+1,+4) | **cliffType 15→1** | L=2, water=F, wh=8192 |

⇒ **规则（A）**：对**已有深水**的角点再次落笔，官方会在**南侧**扩出一片水（设水位 + 把 L 压到 0），并在更外一圈改 `cliffType` ✓
⇒ **不是对称圆形扩张** ✗ —— 这直接否掉了我此前的"统一外扩"实现（见 `CORRECTIONS.md` §15）✓

### 2.2 未解点

2. `wh=8192` 处处相同 ⇒ 水位取值规则未分离
3. 与 §1.2 的 `+y` 不对称是**同一现象**吗

## 8. 关于「`+y` 方向不对称」的假设与判定实验（§1.2 / §2.1 的共同异常）

### 8.1 假设（推断，待实测）

圆形/环形掩码可能**以游标（连续坐标）为圆心**，而不是以角点为圆心。
若实验时鼠标落在角点格内偏南（`fy > 0.5`），圆心会整体南移约 `0.5` 角点 ⇒
现象正好是：**南侧多出一环、北侧少一环** ✓（与 §1.2 的 (31,33)=6、(31,34)(30,34)(32,34)=4 完全吻合）

**旁证**：`ghidra_27d450.c:105-112` 里两个 0/1 选择器来自**浮点坐标与 ≈0.5 的比较** ⇒ 官方确实用连续坐标做过判定 ✓
**反向证据**：坡道的 4 个亚格偏移（±0.25）**没有**改变集合 ⇒ 至少坡道的**3 共线/3×3 选择**不依赖亚格 ✓
⇒ 结论尚未成立：可能"**形状掩码**用游标圆心（受亚格影响）"，而"**轴向判定**用角点（不受亚格影响）" ✓

### 8.2 判定实验（两次会话，各 1 次写盘）

在官方编辑器里对**同一个角点**做「升高一层 ×3」，但鼠标分别落在该角点格内的
**北半（fy≈0.25）** 与 **南半（fy≈0.75）**：

- 若两次的层级剖面**整体平移约 1 角点** ⇒ 假设成立（掩码以游标为圆心）✓
- 若两次剖面**基本重合** ⇒ 假设否掉，需回代码解释 ✗

产出比对方式：`w3e_diff.py --only=layer` + 按距离分组统计（同 §1.1 的表）

### 8.3 若假设成立，对我们实现的影响

`TerrainBrush` 的形状掩码需接受**亚格偏移**（`subX/subY ∈ [0,1)`），圆心 = 角点 + 偏移；
而坡道的"轴向/3×3 判定"仍用角点整数坐标 ✓（与实测一致）
