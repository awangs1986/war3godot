# W3 Terrain Brush Test

这是已经配置完成的独立 Godot .NET 地形笔刷测试工程。

## 直接刷地形

双击 `OPEN_TERRAIN_EDITOR.bat`。Godot 启动后会自动切换到顶部的 `W3 Terrain` 主面板。
右侧是独立地形画布，不经过 Godot 内置 3D 框选工具，因此不会出现系统框选矩形。

- 左键：绘制，按住拖动可连续绘制。
- 右键：转动摄像机。
- 滚轮：高速缩放（旧速度的 5 倍）。
- `Shift + 滚轮` 或 `+/-`：调整笔刷尺寸。
- `Ctrl+Z`：撤销整次笔画。
- `Esc`：关闭笔刷；点击面板中的按钮可重新开启。
- 面板可切换纹理、高度、平滑、悬崖升降以及圆形/方形笔刷。

## 独立回归窗口

双击 `RUN_HIVEWE_VALIDATION.bat` 可以启动之前已经验证通过的独立 HiveWE 流程窗口。
它只用于回归比较；正式编辑入口是 Godot 顶部的 `W3 Terrain`。

## 实现边界

`validation/hivewe` 是隔离的临时验证实现。顶部主面板使用项目自有 C# 代码，
并已接入 Godot 的场景资源和 `EditorUndoRedoManager`。
